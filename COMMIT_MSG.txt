REGLES METIER FIGEES
=====================

13ieme mois :
  - Droit pour TOUS les salaries actifs (sans condition d'anciennete)
  - Formule : BrutRecurrent x MoisPresence / 12
  - Base    : dernier brut recurrent (hors conges et exceptionnels)
  - Verse   : bulletin de decembre (cas normal) OU STC (depart, V1.7.3)
  - Fiscal  : IR + CSS + IPRES + IPM (sans lissage)
  - Provision mensuelle 1/12 sur BR du mois en cours

Gratification :
  - Decision DG, saisie ad hoc par RH
  - Base au choix : BrutRecurrent / NetRecurrent / Forfait
  - Multiplicateur libre
  - Workflow : RH saisit -> DAF valide -> RH integre
  - Reporting a posteriori (pas de provision en amont)

PIEGES RENCONTRES & RESOLUS
============================
1. BulletinLigne n'a PAS de propriete 'Quantite' (CS1061 au 1er build).
   Propriete reelle = 'Taux' (decimal?). Snapshot Base / Taux / Montant.

2. XAF0009 : RuleRequiredField interdit sur value types (int, enum).
   Retire de Annee, MoisPaiement, Statut, BaseCalcul (6 props sur
   TreiziemeMois.cs + Gratification.cs). RuleRange + init dans
   AfterConstruction suffisent.

3. La valeur enum 700/710 n'impose PAS l'ordre d'affichage. C'est
   Rubrique.OrdreAffichage qui pilote (13EME=70, GRATIF=75).

4. Auto-exclusion via CodesExclus (HashSet enum) : un 13ieme ne se
   re-inclut pas dans le BR du 13ieme suivant.

5. Idempotence : Calculer 13ieme n'ecrase pas un statut IntegreeBulletin.

6. NetRecurrent : approche pragmatique = Bulletin.NetAPayer du dernier
   bulletin valide (pas de recalcul complexe IR/cotisations).
