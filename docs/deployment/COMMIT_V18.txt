═══════════════════════════════════════════════════════════════════════════
PROCÉDURE DE DÉPLOIEMENT POST-MERGE
═══════════════════════════════════════════════════════════════════════════

1. Audit duplications BulletinLigne (la contrainte unicité bloquera sinon) :
   SELECT b.Annee, b.Mois, s.Matricule, r.Code, COUNT(*)
   FROM BulletinLigne bl
   INNER JOIN Bulletin b ON b.Oid = bl.Bulletin
   INNER JOIN Salarie s ON s.Oid = b.Salarie
   INNER JOIN Rubrique r ON r.Oid = bl.Rubrique
   WHERE bl.GCRecord IS NULL AND b.GCRecord IS NULL
   GROUP BY b.Annee, b.Mois, s.Matricule, r.Code
   HAVING COUNT(*) > 1;

2. Lancer Deploy-AdiPAIE-V18.ps1 (BACKUP + Stop IIS + copie + restart)

3. Premier accès : Updater XAF ajoute les colonnes SQL automatiquement
   (SoldeConge.SoldeArreteAu/SoldeAVerifier/SourceInitialisation,
   ParametresPaie.ModeBulletinConges/ModeBaseCFCE)

4. Login admin → ParametresPaie → "Init. rôles GRH"
   (re-pose les permissions Create sur BulletinLigne, CongeDemande,
   DemandeDeplacement pour RH/DAF/DG)

5. Login admin → ParametresPaie → "Recharger le référentiel paie"
   (crée la rubrique ICCP et le TypeRef AV_NAT_NON_IMP)

6. SQL post-déploiement pour corriger AV_TEL existante :
   UPDATE Rubrique SET TypeRef = (SELECT Oid FROM RubriqueTypeRef WHERE Code='AV_NAT_IMPOS'),
       BrutFiscal = 1, BrutSocial = 0
   WHERE Code = 'AV_TEL';

7. Décombiner les users RH+Employé (optionnel mais recommandé) :
   DELETE FROM PermissionPolicyUserUsers_PermissionPolicyRoleRoles
   WHERE Roles = (SELECT Oid FROM PermissionPolicyRole WHERE Name = 'Employe')
     AND Users IN (
         SELECT u.Oid FROM PermissionPolicyUser u
         INNER JOIN PermissionPolicyUserUsers_PermissionPolicyRoleRoles ur ON ur.Users = u.Oid
         INNER JOIN PermissionPolicyRole r ON r.Oid = ur.Roles
         WHERE u.GCRecord IS NULL AND r.Name IN ('RH','DAF','DG')
     );

8. (Si bugs d'affichage chez certains users) :
   DELETE FROM ModelDifferenceAspect;
   DELETE FROM ModelDifference;
