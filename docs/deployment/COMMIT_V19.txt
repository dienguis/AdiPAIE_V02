V1.8.6 - Validation/Cloture en masse + workflow bulletin strict
============================================================================

3 bugs corriges d'un coup :

1. ValiderBulletin etait RequireSingleObject -> RequireMultipleObjects
   + boucle sur SelectedObjects (validation en masse enfin possible)

2. CloturerAction_Execute utilisait FirstOrDefault -> 1 seul cloture
   meme si N selectionnes (bug cache !). Fix : boucle sur SelectedObjects.

3. La cloture ne verifiait PAS le statut Valide -> un Brouillon pouvait
   sauter directement en Cloture, sans ValiderRemboursementsPrets ->
   echeances de prets restaient Prevue et se re-facturaient sur le mois
   suivant (DOUBLE PRELEVEMENT).
   Fix : refus strict si Statut != Valide, message clair.

Reouverture idem : boucle sur SelectedObjects, skip silencieux si deja
en Brouillon.

Workflow strict impose : Brouillon -> Valide -> Cloture (sans saut).
