## Notes opérationnelles pour la DSI (interne — pas à envoyer)

### Avant l'envoi des mails

- [ ] Vérifier que les 3 users sont créés dans Administration → Utilisateurs
- [ ] Vérifier que chaque user a bien `Employe` + son rôle métier coché
- [ ] Vérifier que `ChangePasswordOnFirstLogon = true` pour chaque user
- [ ] Vérifier que `StoredPassword` est vide
- [ ] Vérifier que la propriété `Salarie` du user pointe vers la bonne fiche salarié
- [ ] Tester la connexion avec un user fake avant d'envoyer les mails

### Suivi après envoi

- Surveiller dans les 48h que chacun s'est bien connecté
- Vérifier dans les logs ASP.NET Core que pas d'erreur de connexion
- Confirmer que chacun a bien changé son mot de passe (cf. `StoredPassword`
  non vide dans Administration → Utilisateurs)

### Procédure si mot de passe oublié (V1.7.2)

Pas encore de fonction self-service. Procédure manuelle :

1. RH ou DSI va dans Administration → Utilisateurs → ouvrir le user
2. Réinitialiser : `ChangePasswordOnFirstLogon = true`, `StoredPassword = ""`
3. Save
4. Communiquer à l'utilisateur : "Reconnectez-vous avec votre email et un
   mot de passe vide, vous serez invité à en définir un nouveau."

### Roadmap V1.7.3 (à coder) — Self-service "Mot de passe oublié"

- Action "Forgot password?" sur l'écran de login
- Saisie email → envoi d'un lien de reset par mail SMTP
- Lien à durée limitée (24h)
- Reset → définition d'un nouveau mot de passe
