Analyse de l'Effectif (Global / Moyen)

Vue analytique avec toggle Interne/Externe + Global/Moyen, courbe sur 8 ans et 5 bar charts (tranche d'âge, ancienneté, segment, catégorie Top 5, type contrat).

Toggle Personnel

  • Interne = Salariés CDI/CDD/Stage (entité Salarie)
  • Externe = Intérimaires (entité Interimaire + ContratInterim)

Quand on bascule entre les deux, certains filtres changent : Site devient Station service, Département devient Société Intérim, Catégorie devient Poste.

Toggle Mode

  • Global = effectif au 31/12 (photo instantanée)
  • Moyen = (effectif au 1/1 + effectif au 31/12) / 2 (vue ETP annuel)

Évolution sur 8 années glissantes

Sparkline SVG avec aire orange : valeur année par année + variation % vs N-1 (▲ vert = croissance, ▼ rouge = décroissance).

5 bar charts

  1. Tranche d'âge (vertical) — 4 tranches + vide
  2. Ancienneté (vertical) — 5 tranches + vide
  3. Segment (horizontal) — Département (INTERNE) ou BU (EXTERNE)
  4. Catégorie Top 5 (horizontal)
  5. Type de contrat (horizontal)
