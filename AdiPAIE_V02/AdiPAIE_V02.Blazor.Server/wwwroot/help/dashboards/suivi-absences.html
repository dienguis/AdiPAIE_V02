2. Motifs et mapping

Chaque CongeDemande est rattachée à un motif via son CongeType :

  1. Match prioritaire sur CongeType.Code (ex. MAL, AT, CPAYE).
  2. Sinon fallback sur CongeType.Famille (Annuel › CPAYE, Maladie › MAL...).
  3. Pour la famille Maternité : MAT si Sexe = Féminin, sinon PAT.

Les motifs sont regroupés en deux catégories :

  • Absentéisme (compte dans le taux) : maladie, accident de travail, maladie professionnelle, absence injustifiée.
  • Programmées (hors taux d'absentéisme) : congé annuel, maternité, paternité, événement familial, récupération, sans solde.

3. Comment lire le tableau

3.1Évolution mensuelle

Bar vertical 12 mois avec deux séries : absentéisme et absences programmées. Le mois pic du KPI utilise le milieu de chaque période (gère les congés à cheval sur deux mois).

3.2Par motif

Pour chaque motif : nb jours, nb absences, pourcentage du total. Les motifs d'absentéisme sont visuellement distingués des programmées.

3.3Par ancienneté

Tranches 0 an, 1-4 ans, 5-9 ans, 10-14 ans, 15+ ans. Pour chaque tranche : effectif, JO perdus, taux d'absentéisme. Détecte les écarts de comportement par ancienneté.

3.4Par catégorie et par département

Deux tables : ventilation par catégorie professionnelle et par département. Identifie les segments avec le taux d'absentéisme le plus fort.

3.5Liste détaillée des employés absents

Pour chaque salarié ayant eu au moins une absence : décomposition par motif, nb de jours et nb d'absences. Permet d'enquêter sur les top absents.

4. Filtres

  • Statut : Accordées (recommandé, Statut = 20) ou + En attente (élargit à Soumise, En attente N+1, En attente N+2).
  • Année : par défaut l'année en cours.
  • Mois : multi-sélection, vide = toute l'année.
  • Site, Département, Catégorie : regroupements classiques.
  • Motifs : multi-sélection pour cibler certaines familles.

Base de 22 jours ouvrés par mois x 12 mois = 264 jours par an. Cache TTL 5 minutes, bouton Actualiser pour forcer.

5. Dépannage et FAQ

Le taux d'absentéisme me paraît trop faible

Vérifier le filtre Statut : seules les demandes Accordées sont comptées par défaut. Si des arrêts maladie récents sont encore à l'état Soumise, ils ne comptent pas. Basculer en "+ En attente" pour une vue élargie.

Un arrêt maladie apparaît en "programmé"

Le CongeType utilisé n'a pas le bon Code ni la bonne Famille. Ouvrir Congés et absences › Types de congé et corriger : Code MAL ou Famille Maladie.

Un salarié masculin apparaît en MAT au lieu de PAT

Le champ Sexe de la fiche Salarié est mal renseigné (ou vide, par défaut Masculin). Corriger la fiche.

Le total jours semble doublé

Vérifier qu'il n'existe pas deux CongeDemande qui se chevauchent sur la même période pour le même salarié. Le dashboard ne dédoublonne pas les chevauchements.
