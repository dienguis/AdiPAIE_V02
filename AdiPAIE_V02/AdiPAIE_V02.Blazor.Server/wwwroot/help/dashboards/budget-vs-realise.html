Tableau N°7 · V1.2.1 · Vue annuelle

Budget vs Réalisé Masse Salariale

Pilotage annuel de l'écart entre le budget brut validé en CODIR et le réalisé effectif (somme du brut fiscal des bulletins). Vue simplifiée à grains larges, alignée sur la pratique du DAF.

À quoi sert ce tableau

Permet au DAF de répondre instantanément à 3 questions critiques :

  • Suis-je dans le budget cette année ? (écart valeur + %)
  • Comment l'écart évolue-t-il sur les 5 dernières années ? (tendance)
  • Quel site est en dépassement ? (ventilation par station / siège / dépôt)

Pour qui

  • DAF + Contrôle de gestion : revue annuelle ou trimestrielle (avec écart YTD pré-calculé).
  • DG / DAF : arbitrage des dépassements (recrutements à différer, gel de primes).
  • RH Manager : visibilité sur l'enveloppe RH disponible.

Prérequis : saisir le budget annuel

Ce dashboard nécessite que le budget ait été saisi dans Paramétrage → Budget Masse Salariale. La saisie est simple et annuelle :

ChampDescription
AnnéeAnnée du budget (ex : 2026).
SiteOptionnel. Laisser vide pour un budget global non ventilé. Sinon, saisir 1 ligne par site.
Montant brut annuel (FCFA)Enveloppe brute validée en CODIR (avant charges patronales).
SourceSaisie manuelle, Import Excel, Recopie N-1, Données de démo.
CommentaireLibre, optionnel.
💡 Bonne pratique : Saisir 1 ligne globale (Site=vide) pour le total CODIR, puis éventuellement des lignes par site pour la ventilation analytique. L'index unique (Année, Site) empêche les doublons.

Sections du tableau

Évolution sur 5 années glissantes

Tableau de 5 lignes (année N-4 → N) avec :

  • Budget brut annuel
  • Réalisé brut annuel
  • Écart valeur + %
  • Mini-barres comparatives Budget (bleu) vs Réalisé (orange)

L'année sélectionnée dans le filtre apparaît en surbrillance (gras + bord orange à gauche).

Ventilation par site — Année cible

Pour chaque site ayant un budget saisi sur l'année cible :

  • Budget brut
  • Réalisé brut (somme du brut des salariés affectés à ce site)
  • Écart valeur + %

Si des budgets globaux (Site=NULL) existent, ils apparaissent dans une ligne Global (non ventilé).

Filtres disponibles

  • Année : sélection de l'année (par défaut année courante).
  • Site : focus sur un site précis (le filtre conserve aussi les budgets globaux pour cohérence).

Limites connues V1.2.1

  • Pas encore d'export Excel (à venir en V1.2.2).
  • Pas de granularité trimestrielle ni mensuelle (par choix : la consultation est annuelle).
  • Pas de granularité par rubrique (Salaires base / Primes / Charges patronales). On suit le brut consolidé.
  • Le réalisé inclut tous les bulletins (CDI + CDD + Stage). Pas de filtre par type de contrat pour le moment.

Questions fréquentes

QuestionRéponse
Mon écart est de +100 % partout, pourquoi ?Aucun budget saisi pour l'année. Aller dans Paramétrage → Budget Masse Salariale.
Le budget global et les budgets par site se cumulent ?Oui — le KPI "Budget brut annuel" est la somme de toutes les lignes (globales + par site). Idéalement, choisis un seul mode (global OU ventilé) pour éviter le double comptage.
Comment recopier le budget N vers N+1 ?En V1.2.1 : duplication manuelle ligne par ligne (clic droit "Cloner" sur la ligne). En V1.2.2, un bouton "Recopier N-1 + inflation %" sera ajouté.
Pourquoi l'évolution montre 5 ans alors que je n'ai que 3 ans de seed ?Les années sans budget ni bulletin apparaissent à 0. C'est normal.
Le budget peut-il être négatif ?Non — la règle de validation refuse les montants négatifs au save.
