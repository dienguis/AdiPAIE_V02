Tableaux de Bord RH — Guide utilisateur

Le module Tableaux de Bord RH regroupe 6 vues analytiques pour piloter l'effectif, les mouvements, la rémunération et le bilan social de l'entreprise. Chaque tableau possède des filtres (Année, Site, Genre, Catégorie…) et certains proposent un toggle Personnel Interne / Externe.

Périmètre des données : INTERNE = Salariés CDI/CDD/Stage (entité Salarie), EXTERNE = Intérimaires (entité Interimaire + ContratInterim). Les tableaux 1, 5 et 6 sont INTERNE uniquement ; les tableaux 2, 3 et 4 ont un toggle.

Sources de données

Les tableaux de bord lisent en temps réel les entités métier :

  • Salarie + Person — fiche salarié, dates d'embauche / sortie, sexe, catégorie, site, département
  • Interimaire + ContratInterim — intérimaires, contrats, taux journalier, station service
  • Bulletin + BulletinLigne — paie mensuelle, masse brute, charges patronales, rubriques
  • CongeDemande + CongeType — demandes de congé, famille (Annuel / Maladie / etc.)
  • Site, StationService, Departement, Categories, PosteInterimaire — référentiels

Cache et performance

Chaque calcul KPI est caché 5 minutes côté serveur (mémoire). Le bouton ↻ Actualiser permet d'invalider ce cache si vous venez de saisir une donnée fraîche (nouveau salarié, bulletin validé, etc.).
