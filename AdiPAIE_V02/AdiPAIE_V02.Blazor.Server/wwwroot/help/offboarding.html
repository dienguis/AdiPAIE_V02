Offboarding & Solde de tout compte

Flux de travail

  1. RH → Dossiers de depart → Nouveau
  2. Selectionner le salarie → les donnees sont pre-remplies (salaire, anciennete, conges)
  3. Renseigner le Motif de depart, la Date de sortie, et la Duree de preavis
  4. Cliquer Charger donnees salarie pour rafraichir les donnees
  5. Cliquer Calculer le solde → calcul automatique de tous les elements
  6. Cliquer Valider (RH) → approbation RH
  7. Cliquer Valider (DAF) → validation financiere
  8. Cliquer Cloturer le dossier → le salarie est desactive et sa date de sortie enregistree

Boutons disponibles

Charger donnees salarie : charge le salaire de base, l'indemnite de logement, l'anciennete et le solde de conges depuis la fiche du salarie.
Calculer le solde : calcule automatiquement les 4 elements du solde de tout compte (conges non pris, preavis, licenciement, prorata). Passe le statut en "Solde calcule".
Valider (RH) : le RH approuve le solde calcule. Enregistre le nom de l'approbateur et la date.
Valider (DAF) : le DAF valide le montant a payer. Enregistre le nom et la date.
Cloturer le dossier : desactive le salarie (IsActif = false), enregistre la DateSortie. Action irreversible.

Calcul du solde de tout compte

Le calcul suit le droit du travail senegalais (Code du Travail). Les formules sont appliquees automatiquement depuis les donnees snapshot du salarie.

1. Indemnite de conges non pris

Indemnite conges = Jours disponibles × (SalaireBase / 26)

Base : 26 jours ouvrables par mois (convention senegalaise).

2. Indemnite de preavis

Indemnite preavis = (SalaireBase + IndemniteLogement) / 30 × DureePreavis (jours)
Applicable uniquement en cas de licenciement ou de rupture conventionnelle. Les demissions et fins de CDD ne donnent pas lieu a indemnite de preavis.

3. Indemnite de licenciement

Pour chaque annee d'anciennete :
• Annees 1 a 5 : 25% × (SalaireBase + Logement)
• Annees 6 a 10 : 30% × (SalaireBase + Logement)
• Au-dela de 10 ans : 40% × (SalaireBase + Logement)
Applicable uniquement en cas de licenciement ou rupture conventionnelle, et si l'anciennete est d'au moins 1 an.

4. Salaire prorata du mois

Salaire prorata = (SalaireBase + IndemniteLogement) / 30 × Jour de sortie

5. Autres elements

Le champ Autres elements est a saisir manuellement par le RH pour toute prime ou indemnite supplementaire (prime de bilan, gratification, etc.).

Total

TOTAL STC = Conges + Preavis + Licenciement + Prorata + Autres

Erreurs frequentes

"Salarie non renseigne" → Selectionnez un salarie avant de calculer.
"Salaire = 0" → Cliquez "Charger donnees salarie" pour mettre a jour le snapshot.
Conges disponibles = 0 → Verifiez le solde de conges du salarie pour l'annee en cours.
Indemnite licenciement = 0 → Verifie que le motif est "Licenciement" ou "Rupture conventionnelle" ET que l'anciennete est ≥ 1 an.
Boutons grise → Le workflow est sequentiel. Chaque etape doit etre validee avant de passer a la suivante.
