Workflow complet d'une demande de conge

Brouillon Salarie
  ↓ Soumettre
En attente N+1 N+1
  ├→ Valider → En attente N+2 (si N+2 existe) N+2
  │           └→ Valider → Soumise RH
  ├→ Valider → Soumise (si pas de N+2) RH
  └→ Rejeter → Brouillon
Soumise RH
  ├→ Accorder → Accordee (solde debite)
  ├→ Refuser → Refusee
  └→ Modifier les dates → Brouillon
Accordee RH
  └→ Annuler → Annulee

Flux demande de conge Salarie

  1. Mon espace → Mes conges → Nouvelle demande
  2. Choisir type de conge, dates debut/fin, justificatif si necessaire
  3. Le champ Salarie et ValideurN1 sont pre-remplis automatiquement
  4. Cliquer Soumettre → le N+1 recoit une notification par email
  5. Suivre le statut dans "Mes conges" (En attente N+1 → Soumise → Accordee)
  6. Le solde est automatiquement debite a l'accord

Boutons — Demande de conge

Actions du salarie

Soumettre Salarie
Soumet la demande pour validation hierarchique. Disponible uniquement si le statut est Brouillon. Le N+1 (ou le manager) recoit une notification par email. Disponible en ListView et en DetailView.

Actions du N+1 / N+2 (validation hierarchique)

Valider (hierarchie) N+1 / N+2
Valide la demande et la transmet au niveau suivant. Si statut = En attente N+1 : passe en En attente N+2 (si N+2 existe) ou directement en Soumise (pour le RH). Si statut = En attente N+2 : passe en Soumise. Le bouton n'est visible que pour le valideur concerne (comparaison par Oid du salarie connecte).
Rejeter (hierarchie) N+1 / N+2
Rejette la demande et la repasse en Brouillon. Le salarie peut modifier ses dates et resoumettre. La reservation de solde est liberee. Le salarie est notifie par email.

Actions RH

Accorder RH
Accorde le conge. Disponible quand le statut est Soumise. En DetailView, vous devez d'abord renseigner la date de reprise (obligatoire, doit etre apres la date de fin). Le solde de conge est automatiquement debite. Si le type de conge est "Impaye", une retenue sur salaire est creee automatiquement. Le planning est mis a jour et le salarie est notifie.
Refuser RH
Refuse la demande. Le statut passe a Refusee. La reservation de solde est liberee. Le salarie est notifie par email.
Modifier les dates RH
Repasse la demande en Brouillon pour permettre au salarie de modifier les dates. Toutes les validations hierarchiques sont reinitialises (ValideurN1, ValideurN2, dates de validation). Le salarie devra resoumettre apres modification.
Annuler le conge RH
Annule un conge deja accorde. Disponible uniquement quand le statut est Accordee. Le statut passe a Annulee. Le salarie est notifie.

Solde de conges

Chaque salarie a un solde par type de conge et par annee. La formule est :
Solde disponible = Jours acquis + Jours reportes - Jours pris

Boutons sur la fiche SoldeConge (DetailView)

Ajustement manuel RH
Saisissez une quantite dans le champ (ex: +5 pour crediter, -3 pour debiter) puis appuyez sur Entree. Un mouvement de type "AjustementManuel" est enregistre avec le nom de l'utilisateur. Masque pour les employes (consultation seule).
Acquerir mois courant RH
Credite les jours acquis pour le mois en cours sur ce solde specifique. Utile pour une acquisition individuelle (un seul salarie / un seul type de conge). Masque pour les employes.

Boutons sur la liste SoldeConge (ListView)

Lancer acquisition mensuelle RH
Operation batch : credite les jours acquis du mois en cours pour TOUS les salaries actifs. A lancer une fois par mois en debut de periode. Un message de confirmation est demande. Masque pour les employes.
Reporter exercice N → N+1 RH
Operation batch de fin d'annee : reporte les soldes de l'annee precedente vers l'annee en cours, dans la limite des plafonds configures par type de conge. A lancer une fois par an en debut d'exercice. Un message de confirmation est demande. Masque pour les employes.

Planning des conges

Synchroniser le planning RH
Regenere tous les evenements du calendrier a partir des demandes de conge. Les evenements existants sont mis a jour (pas de doublons).
Conges accordes — Filtre le planning pour n'afficher que les conges approuves.
Tous les conges — Affiche tous les conges, quel que soit le statut.
Filtrer par departement — Liste deroulante pour filtrer par departement.

Regles — Droit social senegalais

  • Conge annuel legal : 2,5 jours ouvrables par mois de travail effectif
  • Droit ouvert apres 1 an d'anciennete minimum
  • Report possible selon parametrage du type de conge (plafond configurable)
  • Conge maternite : 14 semaines (6 avant, 8 apres l'accouchement)
  • Le salarie et le N+1 sont pre-remplis automatiquement a la creation

Erreurs frequentes

  • Solde insuffisant → verifier le solde dans "Mon solde de conges". Si necessaire, le RH peut faire un ajustement manuel.
  • Bouton Soumettre invisible → la demande n'est pas en statut Brouillon, ou le champ Salarie n'est pas renseigne.
  • N+1 ne voit pas le bouton Valider → verifier que le ValideurN1 sur la demande correspond bien au salarie du N+1 connecte.
  • Date de reprise obligatoire (Accorder) → en DetailView, renseigner la date de reprise avant de cliquer Accorder. Elle doit etre apres la date de fin.
  • Solde non debite apres accord → verifier que le type de conge a un solde actif pour l'annee en cours.
  • 3 lignes identiques dans Mon solde de conges → il peut y avoir des doublons. Le RH peut verifier et supprimer les doublons depuis la vue complete.
