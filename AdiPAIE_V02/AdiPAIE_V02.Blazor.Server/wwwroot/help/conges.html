✅ Étape 3 — N+1 / N+2 : valider hiérarchie

AN+1 ouvre la demande reçue par email

Menu Mon équipe → Demandes en attente.

BDécision N+1

  • Valider : si N+2 existe → passe en En attente N+2. Sinon → Soumise (transmis au RH).
  • Rejeter : retour en Brouillon, salarié notifié, peut modifier et resoumettre.

CN+2 (si présent) reçoit notification et fait le même choix

Si validé → Soumise (RH).

⚠️ Boutons visibles uniquement pour le valideur concerné (comparaison par Oid du salarié connecté). Un autre N+1 ne pourra pas valider la demande à la place.

🎯 Étape 4 — RH : accorder ou refuser

ARH ouvre les demandes Soumises

Menu GRH → Demandes de congé → filtre rapide « Soumises ».

BAccorder

Renseigner d'abord la Date de reprise (obligatoire, doit être après la date de fin).

Cliquer Accorder.

  • Statut → Accordée
  • Solde de congé du salarié débité automatiquement
  • Si type = « Impayé » → retenue sur salaire créée automatiquement (visible sur le bulletin du mois)
  • Planning de l'équipe mis à jour
  • Salarié notifié par email avec confirmation

CRefuser

Cliquer Refuser avec motif. Statut → Refusée. La réservation de solde est libérée. Salarié notifié.

DModifier les dates (alternative)

Si les dates ne conviennent pas mais le principe est OK : RH clique Modifier les dates. Demande repasse en Brouillon, toutes les validations hiérarchiques sont réinitialisées. Le salarié devra modifier puis resoumettre.

Report annuel

Au 31 décembre, les jours non pris sont reportés sur N+1 jusqu'à un plafond configurable (par défaut 10 jours pour le congé annuel). Le surplus est perdu. Configurable dans Paramétrage → Types de congés.

💼 Cas d'usage concrets

Cas 1 — Congé annuel standard

  1. Mamadou (Salarié) demande 12 jours ouvrables en juillet
  2. Soumet → notification au manager Awa (N+1)
  3. Awa valide → si pas de N+2, passe en Soumise
  4. RH accorde, solde débité de 12 jours
  5. Le mois suivant : pas d'impact bulletin (congé payé)

Cas 2 — Congé sans solde

  1. Salarié demande 1 mois de Sans solde pour raisons personnelles
  2. Workflow normal (N+1 → RH)
  3. RH accorde → retenue automatique créée sur le bulletin du mois
  4. Le bulletin du mois affiche : Salaire base proratisé + ligne « Retenue congé sans solde »

Cas 3 — Maladie avec justificatif

  1. Salarié de retour d'arrêt maladie de 5 jours
  2. Saisit demande type « Maladie » avec dates rétroactives + scan certificat médical
  3. N+1 valide (souvent informé par téléphone avant)
  4. RH accorde, débite le solde Maladie (pas le solde Annuel)
  5. Pas de retenue (maladie payée selon convention)

Cas 4 — Refus pour incompatibilité de planning

  1. Salarié demande congé en juillet (haute saison Boutique)
  2. Manager regarde le planning équipe → trop de monde absent
  3. Manager rejette avec motif → demande repasse en Brouillon
  4. Salarié resoumet sur août

📜 Règles métier et notifications

Règles métier

  • Date de fin ≥ Date de début (contrôle XPO)
  • Date de reprise > Date de fin (saisie au moment de l'accord)
  • Solde disponible vérifié avant Soumission (warning si dépassé)
  • Pour Maladie/Maternité : justificatif obligatoire à l'accord RH
  • Annulation possible uniquement par RH après accord (pas par le salarié)
  • Validations hiérarchiques par Oid : un autre N+1 ne peut pas valider à votre place

❓ FAQ et erreurs fréquentes

Q : Le bouton « Soumettre » est grisé

Causes : dates manquantes, type de congé non sélectionné, solde insuffisant (avec alerte), justificatif manquant pour Maladie/Maternité.

Q : Mon manager ne voit pas le bouton « Valider »

Le bouton n'est visible que pour le ValideurN1 désigné sur la demande. Vérifier que le manager actuel est bien le N+1 (pas un ancien manager ayant changé de poste). Si nécessaire, le RH peut « Modifier les dates » pour réinitialiser les valideurs.

Q : Le solde de congé n'est pas débité après accord

Vérifier dans Mon solde de congé que la ligne SoldeConge correspond bien au type accordé. Si le SoldeConge est en statut « Suspendu », le débit est bloqué. Contacter le RH pour réactiver.

Q : Comment annuler un congé déjà accordé ?

Seul le RH peut annuler après accord. Le salarié doit faire une demande écrite. Le RH ouvre la demande → bouton Annuler le congé. Le solde est recrédité automatiquement.

Q : Un de mes congés apparaît dans le tableau N°5 mais pas l'autre

Le tableau Suivi des Absences affiche par défaut UNIQUEMENT les congés au statut Accordée. Toggle « + En attente » pour voir aussi les Soumises et En attente N+1/N+2.

🎛️ Référence rapide des boutons

Côté Salarié

Soumettre : envoie la demande pour validation. Brouillon → En attente N+1.

Côté N+1 / N+2

Valider (hiérarchie) : approuve le niveau actuel et passe au suivant.
Rejeter (hiérarchie) : retour en Brouillon. Le salarié peut modifier et resoumettre.

Côté RH

Accorder : Soumise → Accordée. Solde débité, retenue auto si Sans solde.
Refuser : Soumise → Refusée. Réservation libérée. Salarié notifié.
Modifier les dates : repasse en Brouillon. Réinitialise les validations hiérarchiques.
Annuler le congé : Accordée → Annulée. Solde recrédité.
