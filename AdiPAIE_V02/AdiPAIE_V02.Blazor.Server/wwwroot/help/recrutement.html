👤➕ Module Recrutement — Guide utilisateur

Pilotage complet du processus de recrutement ELTON, de l'ouverture d'un poste à l'embauche et au suivi de la période d'essai. Ce module couvre 10 entités persistantes et alimente le Tableau de bord N°12 Pilotage Recrutement.

Sommaire — Étapes du processus
  1. Configurer les référentiels (préalable, 1 fois)
  2. Ouvrir un poste vacant
  3. Enregistrer un candidat
  4. Créer une candidature et la faire avancer dans le pipeline
  5. Planifier et noter les entretiens
  6. Proposer une offre d'emploi
  7. Procéder à l'embauche (création fiche Salarié)
  8. Suivre la période d'essai
  9. Piloter via le Dashboard N°12

Vue d'ensemble du pipeline

10 statuts de candidature (workflow numérique pour le tri du funnel) :

Reçue (0) → Pré-sélection (10) → Entretien planifié (20) → Entretien fait (30) → Offre proposée (40) → Offre acceptée (50) → Embauché (60)

États terminaux négatifs : Refusé (90) Désistement candidat (91) Annulé (99)

1 Configurer les référentiels

Quand : une seule fois à l'initialisation du module, ensuite mises à jour ponctuelles.

Qui : DRH ou administrateur.

Menu de navigation

Tous les écrans du module sont regroupés dans le menu GRH - Recrutement de la barre latérale XAF. Vous y trouverez 10 entités classées :

  • Référentiels : Motif d'ouverture poste, Source de recrutement, Motif refus candidat, Motif refus offre
  • Postes & Candidatures : Poste vacant, Candidat, Candidature
  • Suivi : Entretien, Offre d'emploi, Période d'essai

1.1 — Motifs d'ouverture poste

  1. Cliquer sur Motif d'ouverture poste dans le menu
  2. Cliquer + New
  3. Renseigner Code unique (ex: CROISSANCE) + Libellé (ex: Croissance d'activité)
  4. Cocher Actif et Save

Les 3 motifs standards à créer : Croissance d'activité, Remplacement de salarié, Création de fonction.

1.2 — Sources de recrutement (avec coût moyen)

Étape importante car elle alimente le calcul du coût total de recrutement et du coût par embauche.

  1. Cliquer sur Source de recrutement
  2. Pour chaque source : Code unique, Libellé, et surtout Coût moyen / candidat (FCFA)

Exemples de coûts indicatifs au Sénégal :

  • LinkedIn Premium : ~25 000 FCFA / candidat sourcé
  • Recommandation interne : ~5 000 FCFA (prime éventuelle)
  • ANEM (Agence Nationale Emploi) : 0 FCFA (gratuit)
  • Salon emploi : ~40 000 FCFA / candidat (stand + déplacement)
  • Cabinet de chasse : variable (souvent en % du salaire annuel)
💡 Sans le coût renseigné, le KPI "Coût total recrutement YTD" du dashboard restera à 0 FCFA.

1.3 — Motifs de refus (côté entreprise et côté candidat)

Deux référentiels distincts :

  • Motif refus candidat (ELTON refuse) : Manque d'expérience, Habite trop loin, Prétentions trop élevées, Entretien non concluant
  • Motif refus offre (le candidat refuse l'offre) : Rémunération insuffisante, Absence d'opportunités d'évolution, A préféré une autre offre

Ces motifs alimentent le tableau "Motifs de refus" du dashboard et permettent l'analyse stratégique (revoir politique salariale si beaucoup de "Rémunération insuffisante").

2 Ouvrir un poste vacant

Quand : dès qu'un besoin de recrutement est identifié.

Qui : Manager hiérarchique → Validation DRH.

Créer la fiche Poste Vacant

  1. Menu GRH - Recrutement → Poste vacant → + New
  2. Renseigner les champs obligatoires :
    • Code (unique, ex: POSTE-2026-001)
    • Libellé poste (ex: Comptable Senior)
    • Département, Catégorie pro, Site d'affectation
    • Type contrat (CDI / CDD / Stage)
    • Motif d'ouverture (référentiel créé à l'étape 1.1)
    • Expérience requise (années)
    • Profil recherché (description libre)
    • Fourchette salariale Min / Max (FCFA) — la règle valide que Min ≤ Max
  3. Le statut initial est Brouillon
  4. Save

Workflow du poste — 6 statuts

Modifier manuellement le statut au fur et à mesure :

Brouillon → Validé DRH → Publié → En recrutement → Pourvu / Annulé

Le KPI "Postes ouverts" du dashboard compte les statuts Validé / Publié / En recrutement. Le KPI "Délai moyen recrutement" est calculé à partir de DateOuverture jusqu'à la DateCloture au passage à Pourvu.

⚠️ N'oubliez pas de saisir DateCloture au moment du passage en Pourvu, sinon le délai recrutement reste à 0.

3 Enregistrer un candidat

Quand : à la réception d'une candidature (CV).

Qui : DRH ou responsable recrutement.

Créer la fiche Candidat (1 fois par personne)

  1. Menu GRH - Recrutement → Candidat → + New
  2. Référence : code unique candidat (ex: CAND-2026-0001) — facilite la recherche et l'export
  3. Identité : Nom (en MAJUSCULES auto), Prénom, Sexe, Date de naissance
  4. Contact : Email (validation regex), Téléphone, Adresse
  5. Profil : Expérience (années), Compétences clés (texte 1000 car.)
  6. Source initiale : par quel canal le candidat est-il arrivé en base (LinkedIn, Recommandation…) — référentiel créé en 1.2
  7. La date d'inscription est automatiquement remplie
💡 1 fiche Candidat = 1 personne. Si la même personne postule à 3 postes différents, elle a 1 fiche Candidat et 3 fiches Candidature.

4 Créer une candidature et la faire avancer

Quand : à chaque association d'un candidat à un poste vacant.

Créer la candidature

Deux façons de procéder :

  1. Depuis la fiche Candidat : onglet "Candidatures" → + New
  2. Direct : menu Candidature → + New

Champs essentiels :

  • Candidat + Poste visé (FK)
  • Source pour ce poste : peut différer de la source initiale du candidat (ex: candidat connu via LinkedIn mais re-sourcé via Recommandation pour ce poste)
  • Date de soumission (auto = aujourd'hui)
  • Statut initial : Reçue

Faire avancer la candidature dans le pipeline

Modifier le champ Statut au fil du processus :

  1. Reçue → CV bien réceptionné
  2. Pré-sélection → CV qualifié pour la suite
  3. Entretien planifié → RDV pris (créer l'Entretien à l'étape 5)
  4. Entretien fait → après le RDV (renseigner NoteFinale 1-5)
  5. Offre proposée → quand l'OffreEmploi est créée (étape 6)
  6. Offre acceptée → contrat signé, embauche imminente
  7. Embauché → fiche Salarié créée (étape 7) + lien SalarieCree renseigné

États terminaux :

  • Refusé : ELTON refuse — saisir MotifRefusCandidat + DateDecision
  • Désistement candidat : le candidat se retire
  • Annulé : poste annulé en cours de route
⚠️ Faites passer chaque candidature par toutes les étapes du pipeline (ne pas sauter de Reçue à Embauché). Le funnel du dashboard mesure les taux de conversion étape par étape — si vous sautez des étapes, vous perdez la traçabilité.

5 Planifier et noter les entretiens

Créer l'Entretien

  1. Menu Entretien → + New
  2. Lier à la Candidature (FK)
  3. Date entretien + Type (Téléphonique / RH / Technique / Manager / Final / Test pratique)
  4. Intervieweur : choisir le salarié ELTON qui mène l'entretien (FK Salarié)
  5. Lieu / Plateforme : Salle siège, Visio Teams, Téléphone, etc.

Une candidature peut avoir plusieurs entretiens (RH puis Manager puis Final). Chacun doit être créé séparément.

Noter l'entretien après le RDV

Après l'entretien, retourner sur la fiche Entretien et compléter :

  • Note (1-5) : note globale
  • Avis : Très favorable / Favorable / Mitigé / Défavorable
  • Points forts et Points faibles / Réserves (texte libre 2000 car.)
  • Commentaire général

Si plusieurs entretiens existent, la NoteFinale de la Candidature est typiquement la moyenne des notes (à saisir manuellement sur la candidature).

6 Proposer une offre d'emploi

Créer l'Offre

  1. Menu Offre d'emploi → + New
  2. Lier à la Candidature
  3. Date proposition + Validité jusqu'au (date limite de réponse, typiquement +15 jours)
  4. Salaire proposé mensuel (FCFA) : doit être dans la fourchette du Poste
  5. Avantages mensuels (FCFA) : logement, transport, primes diverses
  6. Date prise de poste prévue
  7. Statut initial : Préparée

KPIs calculés automatiquement :

  • Package mensuel total = Salaire + Avantages
  • Délai réponse (jours) = DateRéponse - DateProposition

Workflow de l'offre — 6 statuts

Préparée → Envoyée → Acceptée ✅ / Refusée candidat (saisir MotifRefus) / Retirée entreprise / Expirée

Saisir DateRéponse dès que le candidat répond. Si refusée, le motif côté candidat alimente l'analyse stratégique du dashboard.

7 Procéder à l'embauche

Créer la fiche Salarié

  1. Au moment de l'embauche (Offre Acceptée + signature du contrat) : menu GRH - Salariés → + New
  2. Renseigner la fiche Salarié complète (matricule, identité, salaire base, fonction, IPRES/CSS, etc.) — voir Guide Salariés
  3. Date d'embauche = date de prise de poste effective

Lier la candidature à la fiche Salarié

  1. Retourner sur la Candidature
  2. Changer le statut à Embauché
  3. Renseigner le champ Salarié créé (si embauché) — FK vers la fiche Salarié
  4. Saisir Date de décision = date d'embauche effective
  5. Save

De la même façon, modifier le Poste vacant :

  • Statut → Pourvu
  • Date de clôture = date d'embauche
💡 Cette liaison alimente la traçabilité complète : on peut remonter du Salarié vers sa Candidature → Source → Coût d'acquisition.

8 Suivre la période d'essai

Créer la PeriodeEssai

  1. Menu Période d'essai → + New
  2. Lier à la fiche Salarié nouvellement créée
  3. Optionnel : lier à la Candidature d'origine (traçabilité)
  4. Date début = date d'embauche
  5. Durée prévue (mois) : 3 mois par défaut (CCT Sénégal pour cadres). 1 mois pour employés/ouvriers.
  6. Date fin prévue = Date début + durée
  7. Statut initial : En cours

Clôturer la période d'essai

À l'échéance ou plus tôt en cas de rupture, modifier le statut :

  • Concluante (confirmé) — embauche définitive
  • Prolongée — durée prolongée pour réévaluation
  • Rompue par employeur — saisir motif
  • Rompue par salarié
  • Rupture commune accord

Renseigner Date fin réelle, Évaluation finale (1-5), Appréciation manager, Motif rupture si applicable.

Le KPI Taux rétention post-essai = Concluantes / (Concluantes + Rompues) × 100. Indicateur clé de la qualité du recrutement.

9 Piloter via le Dashboard N°12

Accéder au dashboard

  1. Menu GRH - Tableaux de bord → Pilotage Recrutement
  2. OU URL directe : /dashboards/pilotage-recrutement

Modes Interne / Externe

Toggle Interne / Externe en haut du dashboard :

  • Interne : recrutement de salariés (CDI/CDD/Stage) — vue complète avec funnel, sources, coûts, périodes d'essai. Filtres : Année, Type contrat, Catégories.
  • Externe : recrutement intérimaire (via société d'intérim partenaire). Vue simplifiée car le sourcing est porté par la société d'intérim. Filtre : Année, Sites. Voir le Tableau N°11 — Coût Réel Intérim pour le suivi détaillé.
💡 Au changement de toggle, les filtres sont automatiquement remis à zéro et le cache est invalidé.

Comprendre les 8 KPIs hauts

  1. Postes ouverts : Validés + Publiés + En recrutement
  2. Postes pourvus YTD : Pourvus dans l'année cible
  3. Embauches YTD + Taux conversion (Embauches / Candidatures reçues)
  4. Délai moyen recrutement : DateCloture - DateOuverture sur les Pourvus
  5. Coût total recrutement YTD + Coût moyen / embauche
  6. Candidatures actives : non-terminales
  7. Taux acceptation offres : Acceptées / Envoyées
  8. Périodes d'essai en cours + Taux rétention post-essai

Voir détails complets : Aide Tableau N°12.

Bonnes pratiques de saisie

  • ✅ Saisir les coûts par source au démarrage : sans cela les KPIs financiers restent à 0.
  • ✅ Workflow strict : passer chaque candidature par toutes les étapes du pipeline.
  • ✅ Saisir les motifs de refus : analyse stratégique sinon impossible.
  • ✅ Lier l'embauche à la fiche Salarié : traçabilité complète et création automatique de la PeriodeEssai recommandée.
  • ✅ Date de clôture du poste obligatoire au passage en Pourvu (KPI délai recrutement).
  • ❌ Ne jamais sauter d'étape dans le pipeline (ex: Reçue → directement Embauché).
