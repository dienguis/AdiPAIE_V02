Gestion disciplinaire

Cadre legal (droit senegalais)

Le Code du Travail senegalais distingue trois niveaux de faute :
  • Faute simple : manquement mineur → avertissement ou blame
  • Faute grave : manquement serieux → mise a pied disciplinaire (maximum 8 jours)
  • Faute lourde : manquement rendant impossible le maintien → licenciement immediat
L'audition du salarie est obligatoire avant toute sanction disciplinaire.

Flux de travail

  1. RH → Dossiers disciplinaires → Nouveau
  2. Selectionner le salarie, renseigner la date des faits, la categorie de faute, et la description
  3. Cliquer Notifier le salarie → la date de notification est enregistree
  4. Renseigner la date d'audition → cliquer Programmer audition
  5. Apres l'audition : remplir le PV → cliquer Enregistrer audition
  6. Selectionner le type de sanction et la motivation → cliquer Prononcer la sanction
  7. Cliquer Cloturer le dossier

Boutons disponibles

Notifier le salarie : enregistre la date de notification au salarie. Le salarie est informe de l'ouverture de la procedure.
Programmer audition : planifie la date d'audition. Prerequis : la date d'audition doit etre renseignee.
Enregistrer audition : confirme que l'audition a eu lieu. Prerequis : le PV d'audition doit etre rempli.
Prononcer la sanction : enregistre officiellement la sanction. Prerequis : type de sanction et motivation renseignes. Verifie que la mise a pied ne depasse pas 8 jours.
Cloturer le dossier : archive definitivement le dossier. Le dossier passe en lecture seule.

Mode operatoire detaille

Etape 1 — Ouverture du dossier

  • Aller dans Ressources humaines → Dossiers disciplinaires
  • Cliquer Nouveau
  • Selectionner le salarie concerne
  • Renseigner : Date des faits, Categorie (Simple/Grave/Lourde), Description des faits
  • Optionnel : Articles du reglement interieur enfreints
  • Enregistrer (Ctrl+S)

Etape 2 — Notification

  • Cliquer le bouton Notifier le salarie
  • La date de notification est enregistree automatiquement (aujourd'hui)
  • Remettre en parallele la convocation ecrite au salarie

Etape 3 — Audition

  • Renseigner la date d'audition dans le formulaire
  • Cliquer Programmer audition
  • Le jour de l'audition, remplir le champ Proces-verbal d'audition
  • Renseigner les temoins / representants du personnel si applicable
  • Renseigner les Observations du salarie
  • Cliquer Enregistrer audition

Etape 4 — Sanction

  • Selectionner le Type de sanction dans la liste
  • Si mise a pied : renseigner la duree (max 8 jours)
  • Remplir la Motivation de la sanction (obligatoire)
  • Cliquer Prononcer la sanction
  • Optionnel : joindre la lettre de sanction (PDF)

Etape 5 — Cloture

  • Cliquer Cloturer le dossier
  • Le dossier passe en lecture seule (grise en italique dans la liste)
Important : En cas de licenciement pour faute, il faut egalement creer un Dossier de depart (offboarding) pour gerer le solde de tout compte. Voir Aide Offboarding.

Impact sur le bulletin de paie

En cas de mise a pied, le RH doit ajuster manuellement le champ Jours travailles sur le bulletin du mois concerne. Par exemple, pour une mise a pied de 5 jours : mettre Jours travailles = 25 (au lieu de 30). Voir Aide Bulletins section "Prorata".

Erreurs frequentes

"Renseignez la date d'audition" → Remplissez le champ Date audition avant de cliquer "Programmer audition".
"Remplissez le PV d'audition" → Le champ Proces-verbal est vide. L'audition doit etre documentee avant de passer a la sanction.
"Mise a pied ne peut exceder 8 jours" → La duree saisie depasse le maximum legal. Corrigez la duree.
Boutons grises → Le workflow est sequentiel. Chaque etape doit etre validee dans l'ordre.

Tracabilite

Chaque action (notification, audition, sanction, cloture) est tracee dans le Journal d'audit. Voir Aide Audit.
