Intérimaires - Guide RH

Ce guide decrit le cycle complet de la gestion des intérimaires dans SunuPaie : des salariés d'une societe tierce (SEN INTERIM, ASSI, TECTRA, etc.) mis à disposition d'ELTON Oil Senegal pour une mission sur un site (station, siège, dépôt). Le cycle est : fiche intérimaire, contrat avec affectation site + unités, mouvement en cas de réaffectation, sortie en fin de mission. L'import Excel permet de reprendre en une seule opération la liste globale fournie chaque mois par l'agence d'intérim.

Les entités principales

Interimaire
Fiche de l'intérimaire : identité, matricule interne auto-genere (INT-YYYY-NNNN), matricule attribué par l'agence (MatriculeAgence, utilisé pour rapprocher les factures), société d'intérim de rattachement, statut (Disponible, EnMission, Actif, Inactif, Blackliste), dates d'entrée et de sortie agence. Collections : Contrats, Mouvements, Alertes, Formations, Évaluations.
SocieteInterim
Agence d'intérim : raison sociale, contact, téléphone, email, actif oui/non. Un intérimaire est obligatoirement rattaché à une seule société.
PosteInterimaire
Référentiel des postes (Caissier, Pompiste, Laveur, Magasinier, Chef Boutique, etc.). Partagé entre demandes et contrats.
ContratInterim
Contrat de mise à disposition : dates début/fin, taux journalier FCFA, poste occupé, motif du recours, site d'affectation, unités organisationnelles (multi-affectation). Statuts : Brouillon, EnCours, Termine, Resilie.
MouvementInterimaire
Trace de tout changement d'affectation : site + unité d'origine, site + unité de destination, type (Affectation, Reaffectation, MutationInterne, FinMission, Demission, RuptureContrat), motif, flag ValideRH.
DemandeMouvementInterim
Demande saisie par un Assistant Commercial pour déclencher un mouvement sur un intérimaire en mission. Workflow : Brouillon › Soumise Assistant RH › Validée Assistant RH › Validée RH › (option Validée DAF) › Appliquée. L'application génère un MouvementInterimaire.
AlerteInterimaire
Alerte attachée à un intérimaire : type (MissionExpiree, SansAffectation, FinMissionProche, MouvementNonValide, IncoherenceDonnees, etc.), niveau (Info, Alerte, Urgent), message, date, flag Traitee.

2. Créer une fiche intérimaire

2.1Ouvrir la liste et créer la fiche

Menu : GRH - Intérimaires › Intérimaires, bouton New.

Le Matricule interne est généré automatiquement au format INT-YYYY-NNNN (NNNN = compteur des intérimaires créés dans l'année). Il n'est pas modifiable.

Prénom

Société d'intérim

Champs recommandés pour un dossier complet :

Matricule agence
Identifiant attribué par l'agence (ex. 5196, ETL056). Sert au rapprochement avec les factures mensuelles. Unicité contrôlée.
Sexe
Masculin, Féminin

Catégorie salariale conventionnelle (4ème, 7ème A, 8ème B...)
Date d'entrée agence

Fonction
Poste occupé (texte libre)
N° CNI / Passeport, Date naissance, Nationalité
Identité civile
Email, Téléphone, Adresse

2.3Sauvegarder

Cliquer Save. La fiche affiche en lecture seule l'auteur de création (CreePar) et la DateCreation. Les collections Contrats, Mouvements, Alertes, Formations, Évaluations sont alors utilisables depuis la fiche.

3. Import Excel en masse

L'agence d'intérim fournit chaque mois une « liste globale préso-réseau » au format Excel (typiquement plusieurs centaines de lignes). Le service InterimaireImportService permet de la charger en une opération, avec dry-run obligatoire avant import réel.

3.1Format du fichier attendu

Colonnes attendues dans l'ordre, feuille 1, en-tête ligne 1 :

Col.Contenu

BMatricule (agence) - cle de rapprochement
CPrénoms
DNoms (passés en MAJUSCULES)
ESexe (H/M = Masculin, F = Féminin)
FCatégorie (normalisée : "7EMEA", "7-EME A", "7èmeA" -> "7ème A")
GDate de naissance
HFonction
IBusiness unit (devient une UniteOrganisationnelle)
JAgence d'intérim
KSite d'affectation
LDate d'entrée agence
MAncienneté (ignoré, recalculé par le système)
NNationalité
Normalisations automatiques appliquées à l'import :
  • Agence : "SEN INTERIM", "SEN. INTERIM", "SENINTERIM" -> "SEN INTERIM"
  • BU : "E.SERVICES", "E-SERVICES", "E. SERVICES" -> "E-SERVICES" ; "DEPÔT" -> "DEPOT" ; "CONTRÔLE" -> "CONTROLE"
  • Catégorie : casse et séparateurs normalisés
  • Nom, Fonction, Site : trim, espaces multiples réduits, mise en majuscules sans accents pour la clé

3.2Lancer l'import

Menu : GRH - Intérimaires › Import fichier intérimaires, bouton New.

Le formulaire ImportInterimaireRequest demande :

Fichier Excel
Charger le .xlsx fourni par l'agence (bouton "Charger fichier")
Créer aussi un contrat actif par intérimaire
Coché par défaut. Crée pour chaque intérimaire nouvellement importé un ContratInterim EnCours avec Site + Unité + DateDebut = date d'entrée agence + DateFin = date fin par défaut.
Date fin par défaut des contrats
Par défaut 31 décembre de l'année en cours
Simulation (dry-run)
Coché par défaut. Parse le fichier et produit le rapport SANS rien créer. Décocher pour l'import réel.

Cliquer Save, puis exécuter l'action d'import depuis la fiche.

3.3Lire le rapport

Le champ Rapport détaillé affiche :

  • Lignes lues, Intérimaires créés, Contrats créés
  • Doublons intra-fichier : matricule agence vu plusieurs fois dans le même fichier, premier conservé, suivants ignorés avec numéro de ligne
  • Déjà en base : matricule agence déjà présent dans Interimaire.MatriculeAgence, ligne ignorée silencieusement
  • Agences inconnues : SocieteInterim créées automatiquement si leur RaisonSociale n'existe pas
  • Sites créés auto, Unités (BU) créées auto avec un Code généré au format IMP-<slug> unique
  • Erreurs : lignes avec matricule ou nom vide, ou avec exception, numéro de ligne détaillé
Workflow recommandé : (1) lancer un premier import en dry-run, (2) relire le rapport, créer manuellement les agences / sites / BU que le rapport signale comme auto-générés si on veut leur donner un code plus propre, (3) décocher dry-run et relancer pour l'import réel.

4. Contrat et affectation site/unités

4.1Créer un contrat

Depuis la fiche intérimaire, onglet Contrats, bouton New. OU menu GRH - Intérimaires › Contrats intérim.

Intérimaire
Lookup obligatoire
Type
PremiereMission (par défaut) ou Renouvellement (lier alors ContratPrecedent)
Date de début, Date de fin
Obligatoires. Règle de validation : DateFin >= DateDebut
Taux journalier (FCFA)
Entier, format N0
Poste occupé
Lookup PosteInterimaire actifs
Motif du recours
Texte 300 car. obligatoire (surcroît d'activité, remplacement maladie, projet ponctuel...)
Référence
Numéro de contrat côté société d'intérim (optionnel)

4.2Affecter au site et aux unités

Site
Un seul site parmi les sites actifs (station, siège, dépôt).
Unités
Multi-affectation : une ou plusieurs UniteOrganisationnelle rattachées au site choisi. Pour une station : une BU (Boutique, Piste, E-SERVICES, Espace Auto). Pour le siège : un ou plusieurs départements ou segments.
Les dashboards RH (effectif, mouvements, rémunération, bilan social) lisent uniquement les champs Site et Unites du contrat pour la ventilation. Si ces champs sont vides, le contrat n'apparaît pas dans la vue EXTERNE des tableaux de bord.

4.3Vie du contrat

Statuts :

  • Brouillon : saisie en cours
  • EnCours : statut par défaut à la création, mission active
  • Termine : mission finie (voir section 6 "Sortir un intérimaire")
  • Resilie : rupture anticipée

Alertes visuelles sur la colonne DateFin :

  • Rouge foncé : DateFin dépassée, statut encore EnCours ou Brouillon - prolongation ou sortie à traiter
  • Orange : fin dans 7 jours ou moins
  • Jaune : fin dans 8 à 30 jours

Le champ DateFinReelle est renseigné à la clôture effective (par l'action "Sortir intérimaire" ou manuellement). Le coût total estimé = TauxJournalier x (DateFin - DateDebut) en jours.

5. Mouvement (changement de site ou poste)

Un intérimaire en mission peut être réaffecté sans ouvrir un nouveau contrat : changement de station, changement de poste, mutation interne, remplacement temporaire. Deux voies : saisie directe du mouvement, ou passage par une demande de mouvement.

6. Sortir un intérimaire (fin de mission)

Action en un clic sur la fiche intérimaire. Clôture simultanément la fiche, les contrats actifs et génère le mouvement de sortie.

6.1Déclencher l'action

Ouvrir la fiche de l'intérimaire (DetailView). Dans la barre d'actions, cliquer Sortir intérimaire.

L'action est masquée automatiquement si le statut est déjà Inactif ou Blackliste. Elle n'est pas disponible sur la ListView : il faut ouvrir la fiche pour éviter les sorties accidentelles.

6.2Renseigner la popup

Champs demandés (DTO SortirInterimaireRequest) :

Intérimaire
Rappel du nom (lecture seule)
Contrats en cours à terminer
Nombre calculé (lecture seule)
Date de sortie
Obligatoire, par défaut aujourd'hui
Motif de sortie
Obligatoire : FinMission, Demission, RuptureContrat, FinCDD, Blackliste, Autre
Observations
Texte libre, 500 car. Préfixé automatiquement par [Sortie JJ/MM/AAAA] dans le champ Observations de la fiche.

Cliquer Confirmer la sortie.

6.3Effets en 1 clic

  1. Statut de l'intérimaire : Inactif, ou Blackliste si le motif = Blackliste
  2. DateSortieAgence et MotifSortie renseignés
  3. Tous les ContratInterim EnCours passent à Termine, DateFinReelle = date de sortie si vide
  4. Un MouvementInterimaire est créé, ValideRH = vrai, TypeMouvement déduit du motif (FinMission -> FinMission, Demission -> Demission, RuptureContrat / Blackliste -> RuptureContrat, FinCDD -> FinMission)
  5. Message de confirmation : nombre de contrats terminés + mouvement créé

8. Dépannage et FAQ

Le menu "Intérimaires" n'apparaît pas pour un utilisateur

Permissions manquantes sur son rôle. Les rôles standards qui ont accès au module : Administrators, RH, Assistant RH, Assistant Commercial (en création de demande), DAF (lecture + validation budget). Vérifier le rôle dans Administration › Users › Roles, puis déconnexion/reconnexion.

L'import Excel refuse une ligne : "matricule ou nom vide"

Les colonnes B (Matricule agence) et D (Nom) sont obligatoires. Vérifier le fichier source, re-sauvegarder avec les champs renseignés et relancer en dry-run.

L'import crée un doublon de site ou de BU

Le service déduplique sur Nom en majuscules sans accents, dans la même session d'import. Si une ligne arrive avec un libellé légèrement différent (espace en trop, variante d'orthographe), elle crée une seconde entité avec un Code auto-généré (IMP-<slug>-1, -2, etc.). Après import, fusionner manuellement les doublons dans le référentiel Sites ou Unités.

Un intérimaire sorti réapparaît dans les listes actives

Vérifier son Statut : il doit être Inactif ou Blackliste. Si l'action "Sortir intérimaire" a été interrompue, relancer : elle est masquée seulement quand le statut final est posé.

Un contrat n'apparaît pas dans les dashboards RH (vue EXTERNE)

Les dashboards lisent ContratInterim.Site et ContratInterim.Unites. Si ces champs sont vides, le contrat n'est ventilé nulle part. Ouvrir le contrat, renseigner Site + Unités, sauvegarder, rafraîchir le dashboard.

Une demande de mouvement reste bloquée au statut "Soumise Assistant RH"

L'Assistant RH doit valider ou rejeter depuis la fiche DemandeMouvementInterim. En cas d'absence prolongée, le RH peut court-circuiter l'étape et valider directement.

Le mouvement est créé mais le contrat ne change pas d'affectation

Comportement attendu : MouvementInterimaire trace l'historique mais ne modifie pas automatiquement le contrat. Pour appliquer la nouvelle affectation, éditer ContratInterim et modifier Site + Unites.

Un matricule agence est en doublon dans la base

Le champ MatriculeAgence a une contrainte d'unicité (RuleUniqueValue). Si l'enregistrement est refusé au save, c'est qu'un autre intérimaire porte déjà ce matricule : rechercher le doublon via la liste, consolider les deux fiches avant de ressaisir.
