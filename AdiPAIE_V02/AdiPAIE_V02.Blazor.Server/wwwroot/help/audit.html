Journal d'audit

Objectif

Le journal d'audit trace automatiquement toutes les actions significatives effectuees dans SunuPaie. Chaque entree enregistre : qui a fait quoi, quand, sur quel objet, et avec quels details. Les entrees d'audit sont en lecture seule et ne peuvent pas etre modifiees ou supprimees.

Actions tracees

ModuleActions tracees
Bulletins de paie Valider, Cloturer, Reouvrir
Offboarding (STC) Calculer le solde, Valider RH, Valider DAF, Cloturer
Disciplinaire Notifier, Programmer audition, Enregistrer audition, Prononcer sanction, Cloturer

Mode operatoire — Consultation

  1. Aller dans Administration → Journal d'audit
  2. La liste affiche toutes les entrees, les plus recentes en premier
  3. Utiliser les filtres pour affiner :
    • Par utilisateur : filtrer sur la colonne "Utilisateur"
    • Par entite : filtrer sur "Entite" (Bulletin, DossierOffboarding, etc.)
    • Par date : filtrer sur la colonne "Date"
    • Par action : filtrer sur "Action" (Valider, Cloturer, etc.)
  4. Cliquer sur une entree pour voir les details complets

Cas d'usage

Qui a valide ce bulletin ?

Filtrer : Entite = "Bulletin", Action = "Valider", puis rechercher le libelle du bulletin concerne. L'entree montre l'utilisateur et la date/heure exacte.

Historique complet d'un dossier de depart

Filtrer : Entite = "DossierOffboarding", puis chercher le nom du salarie dans le libelle. Toutes les etapes du workflow (calcul STC, validation RH, validation DAF, cloture) apparaissent avec leurs horodatages.

Audit des sanctions disciplinaires

Filtrer : Entite = "DossierDisciplinaire". Chaque etape de la procedure (notification, audition, sanction, cloture) est tracee avec le nom de l'utilisateur qui l'a effectuee.

Regles importantes

  • Les entrees d'audit sont en lecture seule — aucune modification possible
  • L'audit ne bloque jamais le flux metier — en cas d'erreur d'ecriture audit, l'action principale s'execute quand meme
  • Chaque entree utilise un ObjectSpace separe pour garantir l'integrite
  • Les entrees sont indexees par date, utilisateur et entite pour des recherches rapides
