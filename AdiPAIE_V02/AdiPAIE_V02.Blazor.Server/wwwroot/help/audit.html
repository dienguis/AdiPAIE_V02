🔍 Journal d'audit — Guide complet

Le journal d'audit trace automatiquement toutes les actions significatives dans SunuPaie. Chaque entrée enregistre : qui a fait quoi, quand, sur quel objet, et avec quels détails. Les entrées sont en lecture seule et ne peuvent ni être modifiées ni supprimées.

🔍 Mode opératoire — Consultation

1Aller dans Administration → Journal d'audit

La liste affiche toutes les entrées, les plus récentes en premier.

2Filtrer pour affiner

  • Par utilisateur : filtrer la colonne Utilisateur
  • Par entité : filtrer sur Entité (Bulletin, DossierOffboarding, etc.)
  • Par date : filtrer sur la colonne Date (plage)
  • Par action : filtrer sur Action (Valider, Clôturer, etc.)

3Cliquer sur une entrée

Affiche les détails complets : ancien/nouveau statut, contexte, données associées.

🎯 Cas d'usage concrets

Cas 1 — Qui a validé ce bulletin ?

Filtrer : Entité = Bulletin, Action = Valider, rechercher le libellé du bulletin (DIOP Moussa — 04/2026). L'entrée affiche l'utilisateur et la date/heure exacte.

Cas 2 — Historique complet d'un dossier de départ

Filtrer : Entité = DossierOffboarding, recherche par nom du salarié dans le libellé. Toutes les étapes du workflow (calcul STC → validation RH → validation DAF → clôture) apparaissent avec leurs horodatages.

Cas 3 — Audit des sanctions disciplinaires d'un mois

Filtrer : Entité = DossierDisciplinaire, Action = Prononcer sanction, Date entre 01/05/2026 et 31/05/2026. Liste de toutes les sanctions prononcées en mai avec leurs auteurs.

Cas 4 — Détecter une activité anormale

Filtrer : Utilisateur = compte_X, Action = Réouverture forcée. Permet de vérifier qu'aucune action sensible n'a été effectuée hors de la procédure normale.

📜 Règles métier et garanties

  • Les entrées d'audit sont en lecture seule — aucune modification ni suppression possible
  • L'audit ne bloque jamais le flux métier — en cas d'erreur d'écriture audit, l'action principale s'exécute quand même
  • Chaque entrée utilise un ObjectSpace séparé pour garantir l'intégrité (transaction indépendante)
  • Les entrées sont indexées par date, utilisateur et entité pour des recherches rapides
  • Pas de purge automatique : les entrées sont conservées indéfiniment (à archiver hors-base si volume important au bout de plusieurs années)

❓ FAQ et erreurs fréquentes

💡 Comment exporter le journal d'audit ? Depuis la liste, sélectionner les entrées (filtre + Ctrl+A) → bouton standard XAF Export Excel.
💡 Pourquoi je ne vois pas une action que j'ai faite ? Vérifier que cette action est bien dans la liste des actions tracées (cf. tableau ci-dessus). Toutes les actions ne sont pas tracées (ex. consultation simple n'est pas tracée).
💡 Qui peut consulter le journal d'audit ? Les rôles Administrators et RH_Manager. Les autres rôles n'y ont pas accès (RBAC).
