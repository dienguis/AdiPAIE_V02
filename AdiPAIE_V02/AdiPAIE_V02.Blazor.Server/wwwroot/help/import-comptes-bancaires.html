Import comptes bancaires (RIB) - Guide RH

Ce guide decrit l'import en masse des comptes bancaires de domiciliation des salariés (RIB) depuis un fichier Excel. Un salarié peut porter plusieurs comptes, chacun affecté d'un mode de répartition parmi Reliquat, MontantFixe ou Pourcentage. L'import est idempotent et refusera un numéro de compte déjà présent pour le même salarié. Il s'adresse au RH operationnel chargé de la migration initiale ou de la mise à jour en masse des coordonnées bancaires.

Multi-comptes par salarié

Un même salarié peut porter plusieurs comptes bancaires. Chaque ligne du fichier Excel correspond à un compte. Pour en déclarer plusieurs sur un salarié, il suffit de répéter son matricule sur plusieurs lignes consécutives.

Les 3 modes de répartition du net

Reliquat
Le compte reçoit le net restant une fois les autres comptes servis. Mode par défaut si la colonne est vide. Le champ Valeur est ignoré. Un seul compte Reliquat autorisé par salarié - c'est le compte "par défaut".
MontantFixe
Un montant FCFA fixe est viré sur ce compte chaque mois. La colonne Valeur porte le montant (ex. 50000 pour 50 000 FCFA d'épargne mensuelle).
Pourcentage
Un pourcentage du net est viré sur ce compte. La colonne Valeur porte le pourcentage entre 0 et 100 (ex. 30 pour 30 %). Un contrôle de validation refuse une valeur supérieure à 100.
Combinaison typique : un compte en MontantFixe ou Pourcentage pour une épargne ou un compte joint, et un compte en Reliquat qui absorbe le solde. Le compte Reliquat est obligatoire si le salarié a au moins un autre compte avec un montant fixe ou un pourcentage.

2. Préparer le fichier Excel

2.1Télécharger le modèle vierge

Menu : Paramétrage > Centre d'imports, ouvrir le centre d'imports puis cliquer sur "Modèle Comptes".

Le système télécharge Modele_Import_ComptesBancaires.xlsx avec les en-têtes attendus en ligne 1 et deux lignes d'exemple grisées (une en Reliquat, une en Pourcentage) à remplacer par les données réelles.

2.2Une ligne = un compte bancaire

Garder la ligne 1 intacte (en-têtes). A partir de la ligne 2, saisir un compte par ligne. Pour un salarié multi-comptes, répéter son matricule sur plusieurs lignes.

Les trois colonnes obligatoires sont MatriculeSalarie, Banque et NumeroCompte. Les autres colonnes sont optionnelles mais recommandées pour un RIB complet (CodeBanque, CodeGuichet, CleRib, BIC).

2.3Préserver les zéros de tête des numéros

Les numéros de compte, codes guichet et clés RIB commencent souvent par un ou plusieurs zéros. Formater les cellules en Texte avant de coller les valeurs pour éviter qu'Excel ne supprime les zéros initiaux (par exemple 004002089747 transformé en 4002089747).

4. Lancer l'import

4.1Ouvrir le Centre d'imports

Menu : Paramétrage > Centre d'imports.

Le Centre d'imports regroupe les actions d'import en masse (Salariés, Conjoints, Comptes bancaires). Les deux boutons dédiés aux comptes sont :

  • Modèle Comptes - télécharge un Excel vierge avec en-têtes
  • Importer Comptes - ouvre la popup d'import

4.2Lancer l'import

Cliquer sur "Importer Comptes". Dans la popup :

  1. Dans le champ Fichier Excel (.xlsx), cliquer pour sélectionner le fichier préparé
  2. Cliquer sur "Importer"

Le service parcourt chaque ligne, crée les CompteBancaireSalarie correspondants, et valide la transaction en bloc si au moins une ligne a été créée.

4.3Lire le rapport

A la fin de l'import, un message de synthèse s'affiche :

X créé(s), Y ignoré(s), Z erreur(s).
  • Créé(s) : nombre de comptes effectivement ajoutés
  • Ignoré(s) : lignes sans matricule, ou compte identique déjà présent pour ce salarié (idempotence)
  • Erreur(s) : matricule introuvable, Banque ou NumeroCompte vide, ou autre exception

Le détail ligne par ligne est écrit dans la table d'audit (Audit > CompteBancaireSalarie / Import en masse).

5. Vérification après import

5.1Contrôler sur quelques fiches

Menu : Gestion du personnel > Salariés, ouvrir un salarié qui devait recevoir plusieurs comptes.

Dans l'onglet Comptes bancaires, vérifier :

  • Le nombre de comptes correspond au fichier Excel
  • Le mode (Reliquat / MontantFixe / Pourcentage) est correct
  • La valeur en FCFA ou en % est correcte
  • Le NomTitulaire est bien le nom complet du salarié si laissé vide dans l'Excel
  • Le champ Actif est à Oui pour les comptes à utiliser

5.2Contrôler la cohérence multi-comptes

Pour tout salarié avec plusieurs comptes :

  • Un seul compte Reliquat par salarié
  • Si Pourcentage, la somme des pourcentages des comptes actifs doit rester cohérente (le compte Reliquat absorbe le solde)
  • Aucune valeur de pourcentage supérieure à 100

Ces règles sont contrôlées à la sauvegarde individuelle de chaque compte. Un compte qui enfreint la règle bloque son propre enregistrement, pas les autres.

5.3Relancer l'import en cas de correction

L'import est idempotent sur (Salarié, NumeroCompte). Après correction du fichier Excel (ajout de lignes manquantes, correction d'un numéro de compte sur une nouvelle ligne), relancer "Importer Comptes" sur le même fichier :

  • Les comptes déjà créés sont ignorés
  • Les lignes nouvelles ou corrigées sont créées

Attention : corriger la Banque ou la Valeur d'un compte déjà présent n'est pas couvert par l'import. Il faut l'éditer manuellement sur la fiche du salarié, ou supprimer l'ancien compte puis relancer l'import.

6. Dépannage et FAQ

"Colonne 'MatriculeSalarie' introuvable"

Le fichier a été enregistré sans la ligne d'en-têtes, ou le libellé a été modifié (accent, espace, casse). Repartir du modèle téléchargé via "Modèle Comptes" et conserver la ligne 1 intacte. Les en-têtes attendus sont : MatriculeSalarie, Banque, NumeroCompte, CodeBanque, CodeGuichet, CleRib, BIC, NomTitulaire, Mode, Valeur, Actif, Observations.

"Matricule 'XXX' introuvable"

Le matricule du fichier Excel ne correspond à aucun salarié de SunuPaie. Causes typiques :

  • Le salarié n'a pas encore été créé - lancer d'abord l'import des salariés
  • Faute de frappe sur le matricule (espace, zéro vs lettre O)
  • Matricule présent dans l'ancien système mais pas repris dans la table Salarié

Les zéros de tête du numéro de compte ont disparu

Excel a interprété la cellule comme un nombre. Formater la colonne NumeroCompte en Texte avant de coller les valeurs, ou préfixer les cellules par une apostrophe ('004002089747).

"Le pourcentage ne peut pas dépasser 100%"

Une ligne en mode Pourcentage porte une valeur supérieure à 100 dans la colonne Valeur. Corriger le fichier Excel et relancer l'import (la ligne fautive sera recréée, les autres ignorées car déjà présentes).

Un compte revient en "ignoré" alors que je veux le modifier

L'idempotence porte sur le couple (Salarié, NumeroCompte). Si le numéro existe déjà, la ligne est ignorée sans écraser l'existant. Pour appliquer la modification :

  • Soit éditer manuellement le compte sur la fiche du salarié
  • Soit supprimer le compte existant puis relancer l'import

Comment changer le RIB principal d'un salarié

Sur la fiche du salarié, onglet Comptes bancaires :

  1. Marquer l'ancien compte Reliquat avec Actif = Non
  2. Ajouter un nouveau compte en mode Reliquat avec Actif = Oui

Il ne peut rester qu'un seul compte Reliquat actif à la fois.

Le bouton "Importer Comptes" n'apparaît pas

L'utilisateur n'a pas la permission sur le Centre d'imports. Faire :

  1. Login Admin
  2. Menu Paramètres de paie › Init. rôles GRH, cliquer
  3. Déconnexion/reconnexion de l'utilisateur concerné
