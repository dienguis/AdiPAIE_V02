Import en masse des comptes bancaires

Permet d'importer les comptes bancaires de domiciliation des salariés en masse. Idéal pour la migration initiale depuis un ancien système ou la mise à jour des coordonnées bancaires.

Boutons disponibles

Les boutons apparaissent sur la liste des Salariés.

Modèle Comptes : Télécharge un fichier Excel modèle (Modele_Import_ComptesBancaires.xlsx) avec les en-têtes attendus et 2 lignes d'exemple.
Importer Comptes : Ouvre un popup pour sélectionner votre fichier Excel (.xlsx). Cliquez sur « Importer » pour lancer le traitement.

Modes de répartition

Reliquat (le plus courant) : le salarié reçoit tout son net sur ce compte unique. À utiliser quand il n'y a qu'un seul compte par salarié.

MontantFixe : un montant FCFA déterminé est viré sur ce compte. Utile pour un compte épargne (ex : 50 000 FCFA fixe / mois).

Pourcentage : un % du net est viré sur ce compte. Utile pour répartir le salaire (ex : 30% sur compte joint, 70% sur compte personnel).

Règles de traitement

  • Matricule + Banque + NumeroCompte obligatoires
  • Idempotent : si un compte avec le même NumeroCompte existe déjà pour ce salarié → ligne ignorée.
  • Plusieurs comptes : autorisé. Mettez plusieurs lignes avec le même MatriculeSalarie. Au moins un doit être en mode Reliquat (le compte par défaut).
  • Total Pourcentages ≤ 100% : contrôlé à la sauvegarde.
  • Un seul Reliquat par salarié : contrôlé à la sauvegarde.
  • NomTitulaire vide : rempli automatiquement avec le nom complet du salarié.
