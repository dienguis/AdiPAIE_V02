Bulletins de paie

Flux de travail

  1. Paie → Periodes de paie → Creer/Ouvrir une periode
  2. Liste des salaries actifs → Selectionner → Creer bulletins (periode)
  3. Ouvrir un bulletin → Verifier le champ Jours travailles (prorata)
  4. Cliquer Recalculer
  5. Verifier les lignes → Valider

Boutons disponibles

Sur le bulletin (DetailView)

Recalculer : recalcule toutes les cotisations et retenues (IPRES, CSS, IR, TRIMF, CFCE) depuis le parametrage salarie. Detecte automatiquement le prorata si c'est un premier bulletin avec embauche en cours de mois.
Valider : passe le bulletin en statut Valide. Marque automatiquement les echeances de prets du mois comme "Prelevees".
Remplacer depuis le modele : supprime toutes les lignes et repart de zero depuis le modele du salarie.
Charger depuis le modele : ajoute les lignes manquantes sans ecraser les lignes existantes.
Remplacer lignes du modele uniquement : recharge les lignes issues du modele, mais garde les lignes manuelles.
Recharger lignes standard : met a jour SB, LOGT, Sursalaire, Transport depuis la fiche salarie.
Reordonner lignes : renumerote les lignes en 10, 20, 30...
Renvoyer (PDF archive) : renvoie par email le PDF deja genere.

Sur la liste des bulletins (ListView)

Telecharger PDF : genere et telecharge le bulletin selectionne en PDF. Si une archive existe, elle est servie directement. Sinon le PDF est genere a la volee et archive pour les prochains telechargements. Visible uniquement pour le RH/Admin.
Envoyer au salarie : envoie le bulletin PDF par email au salarie concerne. Le bulletin doit etre au minimum en statut Valide (pas Brouillon). Le statut passe automatiquement a Envoye. Visible uniquement pour le RH/Admin.
Filtre rapide : filtre predetermine pour retrouver rapidement les bulletins. Options disponibles :
  • Tous : affiche tous les bulletins (retire le filtre)
  • Mois en cours : bulletins du mois actuel
  • Mois precedent : bulletins du mois precedent
  • Brouillons : bulletins en statut Brouillon
  • Valides (non envoyes) : bulletins valides mais pas encore envoyes
  • Envoyes : bulletins deja envoyes au salarie
  • Clotures : bulletins clotures definitivement
Cloturer : cloture le bulletin (irreversible sauf reopening RH). Verifie que tous les bulletins anterieurs sont clotures.
Reouvrir : remet le bulletin en Brouillon. Annule les prelevements de prets du mois, remet les echeances en "Prevue", et recalcule le bulletin.

Sur Periodes de paie (ListView)

Generer etat 1024 : exporte la declaration annuelle des salaires (DGID Senegal) en Excel.
Generer etat VRS : exporte l'etat mensuel VRS (Versement Retenue a la Source) en Excel. Colonnes : Matricule, Statut, Nom, BRUT, IR, TRIMF, CFCE, IPRES (RG/RC salarie et employeur), CSS (AT/AF), NET. Avec totaux et sous-totaux par groupe.

Prorata — Jours travailles

Chaque bulletin a un champ Jours travailles (defaut : 30). Ce champ controle le prorata du salaire de base et de l'indemnite de logement. Il est modifiable par le RH directement sur le bulletin, sans toucher a la fiche salarie.

Cas d'utilisation

SituationJours travaillesQui modifie ?
Salarie normal, mois complet30Automatique (defaut)
Nouvelle recrue embauche le 17 du mois14Automatique au Recalcul (premier bulletin detecte)
Arret pour faute (10 jours non payes)20Le RH modifie manuellement
Absence non payee (5 jours)25Le RH modifie manuellement

Formule de calcul

Salaire de base = (SalaireBase / 30) × JoursTravailles
Indemnite logement = (IndemniteLogement / 30) × JoursTravailles

Fonctionnement automatique

  • Quand le RH clique Recalculer sur un bulletin neuf : si la DateEmbauche tombe dans le mois du bulletin et qu'il n'y a aucun bulletin anterieur, les jours travailles sont calcules automatiquement : 30 - (jour embauche - 1).
  • Si le RH a deja modifie JoursTravailles (valeur != 30), le recalcul ne l'ecrase pas.
  • Le mois suivant, JoursTravailles revient a 30 automatiquement (nouveau bulletin).

Controle date d'embauche

Un bulletin ne peut pas etre cree pour un mois anterieur a la date d'embauche.
Exemple : un salarie recrute le 17/04/2026 ne peut pas avoir de bulletin pour mars 2026 ou avant.
  • En generation batch : le salarie est simplement ignore (compte dans les "ignores").
  • En creation manuelle : une erreur s'affiche a la sauvegarde avec le message : "Impossible de creer un bulletin pour 03/2026. [Nom] n'a ete recrute(e) que le 17/04/2026."

Regles metier

  • Le bulletin doit etre en Brouillon pour etre modifie
  • Valider integre automatiquement le remboursement des prets du mois
  • Les lignes avec Source=Calcul sont recalculees automatiquement
  • Les lignes manuelles ne sont PAS recalculees (intentionnel)
  • Pour forcer le recalcul de SB/LOGT : utiliser "Recalculer"
  • Les cotisations IPRES/CSS sont calculees sur le Brut Social
  • L'IR et la TRIMF sont calcules sur le Brut Fiscal
  • La CFCE est une charge patronale uniquement (pas de retenue salarie)

Verrouillage optimiste

Le bulletin est protege par un verrouillage optimiste : si deux utilisateurs modifient le meme bulletin en meme temps, le deuxieme a enregistrer recoit un message d'avertissement et doit rafraichir la page (F5) avant de reessayer. Cela evite les ecrasements de donnees involontaires.
Message "Ce bulletin a ete modifie par un autre utilisateur" : un autre RH a modifie et enregistre ce bulletin pendant que vous travailliez dessus. Rafraichissez la vue (F5) pour charger la version a jour, puis refaites vos modifications si necessaire.

Heures supplementaires

Si le module HS est active (voir Aide Heures Sup.), un bouton Ajouter HS apparait sur le bulletin. Les heures supplementaires sont calculees automatiquement et integrees dans le Brut.

Erreurs frequentes

SB ou LOGT = 0 → cliquer "Recalculer". Verifier aussi que la fiche salarie a un SalaireBase et IndemniteLogement renseignes.
Pret non visible → verifier que le pret est En cours et que la date echeance correspond au mois du bulletin. Voir Aide Prets.
IR = 0 → verifier les parts fiscales du salarie et le bareme IR parametre.
"Impossible de creer un bulletin..." → la DateEmbauche du salarie est posterieure au mois du bulletin. Le premier bulletin possible est le mois d'embauche.
JoursTravailles revient a 30 apres Recalcul → cela se produit uniquement si la valeur etait deja a 30 ou 0. Si vous avez mis une valeur specifique (ex: 20), elle est preservee.
"Ce bulletin a ete modifie par un autre utilisateur" → conflit de verrouillage optimiste. Rafraichissez la vue (F5) et reessayez.
"Un bulletin existe deja pour ce salarie sur cette periode" → un bulletin avec le meme salarie, annee et mois existe deja. Chaque salarie ne peut avoir qu'un seul bulletin par mois.
"Les montants d'une ligne de bulletin ne peuvent pas etre negatifs" → la base, le montant salarie ou le montant employeur d'une ligne est negatif. Corrigez la saisie.
