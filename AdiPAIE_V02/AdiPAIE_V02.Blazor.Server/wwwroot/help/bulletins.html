📄 Étape 2 — Créer les Bulletins (batch ou manuel)

ACréation en lot (recommandé)

Depuis la fiche Période de paie ouverte :

  1. Onglet Liste des salariés actifs
  2. Sélectionner les salariés (Ctrl+A pour tout)
  3. Cliquer Créer bulletins (période)

Le système crée un bulletin Brouillon par salarié avec les lignes standard (SB, LOGT, Sursalaire, Transport) tirées de la fiche.

BCréation manuelle

Menu Paie → Bulletins → + New → choisir le Salarié et la Période.

Exemple : Mai 2026, 47 salariés actifs.
- Ouvrir la Période 05/2026
- Onglet « Salariés actifs » → tout sélectionner (47 lignes)
- Cliquer Créer bulletins
- Résultat : 47 bulletins en Brouillon (les nouveaux embauchés ce mois-ci ont un prorata auto-calculé)

✏️ Étape 3 — Vérifier les Jours travaillés (prorata)

Chaque bulletin a un champ Jours travaillés (défaut : 30). Il pilote le prorata du Salaire de Base et de l'Indemnité de Logement.

Tableau des cas typiques

SituationJours travaillésQui modifie ?
Salarié normal, mois complet30Automatique (défaut)
Embauche le 17 du mois14Automatique au Recalcul (1er bulletin détecté)
Arrêt pour faute (10 jours non payés)20RH manuel
Absence non payée 5 jours25RH manuel
Salaire de base = (SalaireBase / 30) × JoursTravailles
Indemnité logement = (IndemniteLogement / 30) × JoursTravailles
⚠️ Une fois modifié manuellement (≠ 30), le Recalcul ne l'écrase pas. Le mois suivant, JoursTravailles revient à 30 automatiquement (nouveau bulletin).

🔄 Étape 4 — Recalculer les cotisations

1Cliquer le bouton Recalculer

Sur la fiche bulletin → bouton Recalculer.

Ce que fait le Recalculer :
  • Recharge le SB / LOGT / Sursalaire / Transport depuis la fiche salarié
  • Recalcule l'IPRES RG (5,60% / 8,40%, plafond 432 000)
  • Recalcule l'IPRES RC pour cadres (2,40% / 3,60%, plafond 1 296 000)
  • Recalcule la CSS (AT/AF) — variable selon paramétrage
  • Recalcule la CFCE — variable selon paramétrage
  • Recalcule l'IR (abattement 30%, max 75 000/mois) sur Brut Fiscal
  • Recalcule la TRIMF (Taxe Représentative IMF) sur Brut Fiscal
  • Détecte automatiquement le prorata si premier bulletin avec embauche en cours de mois
Exemple : Bulletin Mai 2026 de Awa SOW (Cadre)
- Salaire base : 1 200 000 FCFA → IPRES RC déclenchée
- IPRES RG salariale : 432 000 × 5,60% = 24 192
- IPRES RG patronale : 432 000 × 8,40% = 36 288
- IPRES RC salariale : (1 200 000 − 432 000) × 2,40% = 18 432
- IPRES RC patronale : 27 648
- Brut Fiscal calculé puis IR/TRIMF appliqués

✅ Étape 5 — Valider

1Cliquer Valider

Bouton Valider sur la fiche du bulletin.

Effets de la Validation :
  • Statut Brouillon → Validé
  • Les lignes deviennent figées (sauf réouverture)
  • Les échéances de prêts du mois sont marquées « Prélevées » automatiquement
  • Le bulletin devient envoyable au salarié (Étape 6)

📧 Étape 6 — Télécharger / Envoyer le PDF

ATélécharger PDF (test/archive)

Liste des bulletins → sélectionner → bouton Télécharger PDF. Génère et télécharge le PDF (archivé pour les prochains téléchargements).

BEnvoyer au salarié (par email)

Liste des bulletins → sélectionner → bouton Envoyer au salarié. Le bulletin doit être au minimum Validé. Le statut passe automatiquement à Envoyé.

Boutons Visible uniquement pour le RH/Admin. Le salarié reçoit le PDF dans sa boîte email professionnelle (renseignée sur sa fiche).

🔒 Étape 7 — Clôturer le bulletin

En fin de mois (et après vérification de tous les bulletins) :

1Cliquer Clôturer

Liste des bulletins → sélectionner → bouton Clôturer. Vérifie que tous les bulletins antérieurs sont clôturés.

⚠️ Action irréversible sauf réouverture par RH/Admin via le bouton Réouvrir qui :
  • Remet le bulletin en Brouillon
  • Annule les prélèvements de prêts du mois
  • Remet les échéances en « Prévue »
  • Recalcule le bulletin

💼 Cas d'usage concrets

Cas 1 — Première paie d'un nouvel embauché

  1. Salarié embauché le 17/04/2026 (DateEmbauche)
  2. Au mois d'avril, le RH crée le bulletin (Période 04/2026)
  3. Recalcul → JoursTravailles auto-calculé : 30 − (17 − 1) = 14
  4. Salaire base proratisé : (1 000 000 / 30) × 14 = 466 667 FCFA
  5. Cotisations calculées sur la base proratisée
  6. Mai 2026 : nouveau bulletin avec JoursTravailles = 30 automatiquement

Cas 2 — Absence non payée de 5 jours

  1. Le salarié a 5 jours d'absence non justifiée en juin
  2. RH ouvre le bulletin Brouillon → modifie JoursTravailles : 30 → 25
  3. Cliquer Recalculer → SB et LOGT sont proratisés à 25/30
  4. Cotisations recalculées sur le nouveau brut
  5. Valider

Cas 3 — Erreur découverte après envoi

  1. Bulletin déjà Envoyé au salarié, erreur découverte (mauvais sursalaire)
  2. Admin clique Réouvrir → bulletin repasse Brouillon
  3. RH corrige la ligne erronée → Recalculer → Valider
  4. RH clique Renvoyer (PDF archive) → email reparti automatiquement

📜 Règles métier

  • Le bulletin doit être en Brouillon pour être modifié
  • Valider intègre automatiquement le remboursement des prêts du mois
  • Les lignes avec Source=Calcul sont recalculées automatiquement
  • Les lignes manuelles ne sont PAS recalculées (intentionnel)
  • Pour forcer le recalcul de SB/LOGT : utiliser « Recalculer »
  • Les cotisations IPRES/CSS sont calculées sur le Brut Social
  • L'IR et la TRIMF sont calculés sur le Brut Fiscal
  • Un bulletin ne peut PAS être créé pour un mois antérieur à la DateEmbauche

❓ FAQ et erreurs fréquentes

Q : Erreur « Impossible de créer un bulletin pour 03/2026 »

Cause : le salarié a été embauché APRÈS le 31/03/2026. Un bulletin ne peut pas être créé pour un mois antérieur à la DateEmbauche.

Fix : vérifier la DateEmbauche sur la fiche salarié. Si la date est correcte, le salarié n'a tout simplement pas droit à un bulletin pour ce mois.

Q : Comment réintégrer une ligne manuelle après un Recalcul ?

Les lignes manuelles ne sont jamais écrasées par Recalculer. Si vous l'avez supprimée par erreur via « Remplacer depuis le modèle », il faut la recréer manuellement.

Q : Le bouton « Envoyer au salarié » ne fonctionne pas

Vérifier :
  • Le bulletin est Validé (pas Brouillon)
  • Le salarié a un email renseigné dans sa fiche
  • Le serveur SMTP est paramétré (Paramétrage → Notifications)

Q : Je dois proratiser SEULEMENT le Sursalaire (pas SB)

JoursTravailles ne touche QUE SB et LOGT. Pour proratiser une autre ligne, modifier directement le Montant de la ligne dans le bulletin (mode manuel). Le Recalcul ne touchera plus à cette ligne.

🎛️ Référence rapide des boutons

Sur la fiche Bulletin (DetailView)

Recalculer : recalcule toutes les cotisations + retenues + détecte prorata.
Valider : passe en statut Validé + marque les échéances de prêts comme Prélevées.
Remplacer depuis le modèle : supprime toutes les lignes et repart de zéro.
Charger depuis le modèle : ajoute les lignes manquantes sans écraser.
Remplacer lignes du modèle uniquement : recharge les lignes du modèle, garde les manuelles.
Recharger lignes standard : met à jour SB, LOGT, Sursalaire, Transport.
Réordonner lignes : renumérote en 10, 20, 30…
Renvoyer (PDF archive) : renvoie par email le PDF déjà généré.

Sur la liste des Bulletins (ListView)

Télécharger PDF : génère/télécharge le bulletin sélectionné. Visible RH/Admin.
Envoyer au salarié : email du PDF. Bulletin doit être Validé. Visible RH/Admin.
Filtre rapide : Tous, Mois en cours/précédent, Brouillons, Validés non envoyés, Envoyés, Clôturés.
Clôturer : action irréversible. Vérifie clôture des bulletins antérieurs.
Réouvrir : remet en Brouillon, annule prélèvements prêts, recalcule.

Sur la liste des Périodes de paie

Générer état 1024 : exporte la déclaration annuelle des salaires (DGID Sénégal) en Excel.
Générer état VRS : exporte l'état mensuel Versement Retenue à la Source en Excel (Matricule, Statut, Nom, BRUT, IR, TRIMF, CFCE, IPRES, CSS, NET avec totaux).
