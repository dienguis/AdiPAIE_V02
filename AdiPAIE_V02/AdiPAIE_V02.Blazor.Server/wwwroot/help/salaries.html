👨‍👩‍👧‍👦 Étape 5 — Onglet Famille

Sous-grilles dans la fiche :

  • Conjoints : nom, profession, à charge fiscalement (oui/non)

💼 Cas d'usage concrets

Cas 1 — Embauche d'un nouveau salarié

  1. RH crée la fiche salarié (Étapes 1-6 ci-dessus)
  2. RH crée le compte XAF (Étape 7) avec UserName = Email
  3. Le salarié reçoit son login + mot de passe initial
  4. Au mois courant : le bulletin est créé avec prorata auto (cf. Bulletins)

Cas 2 — Promotion / Changement d'échelon

  1. Modifier l'Échelon dans l'onglet Contrat
  2. Vérifier la cohérence Catégorie ↔ Échelon
  3. Mettre à jour Salaire base si nécessaire
  4. Le prochain bulletin tiendra compte du nouveau salaire
  5. Tracer l'avancement dans le module Avancements

Cas 3 — Sortie d'un salarié

  1. Renseigner Date de sortie + Motif de départ
  2. Le salarié n'apparaît plus dans la liste « Salariés actifs »
  3. Créer le dossier offboarding (cf. Offboarding)
  4. Désactiver le compte XAF

📜 Règles métier et contrôles automatiques

Contrôles à l'enregistrement

Q : Le salarié n'arrive pas à se connecter

Causes possibles :
  • UserName du compte XAF ≠ Email de la fiche salarié
  • Compte XAF désactivé (case « Active » décochée)
  • Mot de passe incorrect (utiliser « Mot de passe oublié »)
  • Aucun rôle assigné (au minimum Default)

Q : Comment changer le matricule ?

Le matricule est en lecture seule après création. Pour le changer, il faut passer par un script SQL côté DBA, ou archiver l'ancien salarié et en créer un nouveau (déconseillé car perd l'historique).

Q : Le salarié n'apparaît pas dans la liste « Actifs »

Vérifier qu'il n'a pas de Date de sortie renseignée. Un salarié est considéré « actif » si : DateEmbauche ≤ aujourd'hui ET (DateSortie est vide OU DateSortie > aujourd'hui).
