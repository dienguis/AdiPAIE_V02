Heures supplementaires

Activation du module

Le module Heures supplementaires est desactive par defaut. Pour l'activer :
  1. Aller dans Parametrage → Parametres de paie
  2. Onglet Heures supplementaires
  3. Cocher Activer les heures supplementaires
  4. Verifier les taux de majoration (pre-remplis avec les taux legaux senegalais)
  5. Enregistrer
Tant que le module est desactive, le bouton "Ajouter HS" n'apparait pas sur les bulletins et la collection Heures supplementaires est masquee.

Taux de majoration legaux (Senegal)

Le Code du Travail senegalais prevoit quatre niveaux de majoration :

Type Taux de majoration Quand
Jour ouvrable 15% Heures supplementaires en journee, du lundi au samedi
Nuit 40% Heures supplementaires de nuit (21h à 5h), jours ouvrables
Dimanche / Jour ferie 60% Heures supplementaires le dimanche ou un jour ferie, en journee
Nuit dimanche / Jour ferie 100% Heures supplementaires la nuit du dimanche ou d'un jour ferie
Ces taux sont modifiables dans Parametres de paie → Heures supplementaires. Si un taux est mis a 0, le systeme utilise automatiquement le taux legal par defaut.

Methode de calcul

Taux horaire de base

Taux horaire = Salaire de base mensuel / 173,33 heures

Les 173,33 heures correspondent a la duree legale mensuelle : 40 heures × 52 semaines / 12 mois.

Calcul par ligne d'heures supplementaires

Montant base = Nombre d'heures × Taux horaire
Montant majoration = Montant base × Taux majoration / 100
Montant total = Montant base + Montant majoration

Integration au bulletin

Le total de toutes les lignes HS est regroupe dans une ligne de gain unique avec la rubrique canonique HeuresSupplementaires. Ce montant entre dans le Brut Fiscal et le Brut Social (si la rubrique est parametree ainsi).

Exemple concret

Salarie : Moussa DIOP — Salaire de base : 300 000 FCFA

Taux horaire : 300 000 / 173,33 = 1 731 FCFA/h

Type Heures Taux maj. Montant base Majoration Total
Jour ouvrable (15%) 8h 15% 13 848 2 077 15 925
Nuit (40%) 4h 40% 6 924 2 770 9 694
Dimanche (60%) 6h 60% 10 386 6 232 16 618
Total heures supplementaires 42 237 FCFA

Ce montant de 42 237 FCFA apparait comme une ligne de gain "Heures supplementaires" dans le bulletin et s'ajoute au Brut.

Mode operatoire

  1. Ouvrir le bulletin du salarie (statut Brouillon)
  2. Cliquer sur le bouton Ajouter HS
  3. Dans le popup :
    • Choisir le Type d'heure supplementaire
    • Saisir le Nombre d'heures
    • Le taux de majoration s'affiche automatiquement
  4. Cliquer OK → la ligne HS est creee et le bulletin est recalcule
  5. Repeter pour d'autres types d'heures si necessaire
  6. Verifier la ligne "Heures supplementaires" dans les gains du bulletin
  7. Valider le bulletin

Modifier ou supprimer des heures supplementaires

  • Les lignes HS sont visibles dans la collection Heures supplementaires du bulletin
  • Vous pouvez modifier le nombre d'heures ou le type directement dans la collection
  • Pour supprimer : selectionnez la ligne HS et supprimez-la
  • Apres toute modification, cliquez Recalculer pour mettre a jour le bulletin

Regles metier

  • Les heures supplementaires ne peuvent etre ajoutees que sur un bulletin en Brouillon
  • Le taux horaire est calcule automatiquement depuis le Salaire de base du salarie
  • Les taux de majoration sont lus depuis Parametres de paie (modifiables par l'administrateur)
  • Le montant total des HS est integre comme un gain dans le bulletin (rubrique canonique HeuresSupplementaires)
  • Les HS entrent dans le calcul du Brut Fiscal et du Brut Social
  • Toutes les cotisations (IPRES, CSS, IR, TRIMF) sont recalculees en tenant compte des HS
  • Si le module est desactive dans les parametres, les lignes HS existantes sont ignorees au recalcul

Rubrique a creer

Pour que les heures supplementaires apparaissent dans le bulletin, il faut creer une rubrique avec :
  • Canonique : HeuresSupplementaires
  • Type calcul : Gain
  • Brut Fiscal : Oui
  • Brut Social : Oui
  • Code : HS (suggestion)
  • Libelle : Heures supplementaires

Erreurs frequentes

Bouton "Ajouter HS" invisible → le module est desactive. Aller dans Parametres de paie → Heures supplementaires → cocher "Activer les heures supplementaires".
Ligne HS a 0 dans le bulletin → verifier qu'une rubrique avec le canonique HeuresSupplementaires existe et est active. Voir la section Parametrage ci-dessus.
Taux horaire a 0 → le Salaire de base du salarie est probablement a 0. Verifier la fiche salarie.
"Le bulletin doit etre en Brouillon" → les HS ne peuvent etre ajoutees que sur un bulletin non valide. Reouvrir le bulletin si necessaire.
