Heures supplémentaires - Guide RH

Ce guide decrit la saisie et le calcul des heures supplémentaires dans SunuPaie, conformément au barème de la CCT Sénégal : 15 % (jour ouvrable), 40 % (nuit), 60 % (dimanche / jour férié), 100 % (nuit du dimanche ou du jour férié). Les montants sont intégrés comme gain unique au Brut Fiscal et au Brut Social du bulletin du mois. Il s'adresse au RH operationnel qui saisit les heures sur les bulletins en brouillon.

2. Saisir des heures supplémentaires

Pré-requis : le bulletin doit être au statut Brouillon. Un bulletin validé n'accepte pas de saisie HS. Le module doit être activé dans Paramètres de paie.

2.1Activer le module (une fois)

Menu : Paramétrage › Paramètres de paie.

  • Cocher ActiverHeuresSupplementaires
  • Vérifier les 4 taux (TauxHS_JourOuvrable = 15, TauxHS_Nuit = 40, TauxHS_DimancheFerie = 60, TauxHS_NuitDimancheFerie = 100)
  • Enregistrer

Tant que ActiverHeuresSupplementaires est faux, le bouton "Ajouter HS" est masqué sur les bulletins (contrôlé par BulletinHeuresSupController).

2.2Ouvrir le bulletin cible

Menu : Bulletins, ouvrir le bulletin du mois pour le salarié concerné.

Vérifier :

  • Statut = Brouillon
  • Le salarié a un SalaireBase > 0 (indispensable pour le taux horaire)

2.3Cliquer sur "Ajouter HS"

Dans la popup HeureSupplementaireParam, renseigner :

  • Type : JourOuvrable, Nuit, DimancheFerie ou NuitDimancheFerie. Le taux de majoration se met à jour automatiquement à la sélection.
  • Nombre d'heures : entre 0,25 et 744 (règle RuleRange).
  • Taux majoration : affiché en lecture seule, repris depuis ParametresPaie.GetTauxHS(TypeHS).

Valider la popup. Le système :

  1. Crée l'objet HeureSupplementaire rattaché au bulletin
  2. Calcule le taux horaire via CalculerTauxHoraireBase
  3. Calcule base, majoration et total via RecalculerMontants
  4. Enregistre, puis appelle Bulletin.RecalculerSurGrilleExistante()
  5. Affiche un message de confirmation : "N,NNh (Type) ajoutées - X FCFA"

2.4Répéter pour chaque type d'heure

Plusieurs lignes HS peuvent coexister sur un même bulletin (une par type, voire plusieurs du même type si on sépare par motif via le champ Commentaire). Toutes sont agrégées dans une seule ligne de gain du bulletin.

3. Calcul automatique (formules)

Taux horaire de base

Taux horaire = SalaireBase mensuel / 173,33

La constante HEURES_MENSUELLES_LEGALES = 173,33 correspond à la durée légale sénégalaise : 40 heures hebdomadaires x 52 semaines / 12 mois. Si SalaireBase est à 0 ou introuvable, le taux horaire reste à 0 et la ligne HS vaudra 0.

Montants d'une ligne HS

MontantBase = NombreHeures x TauxHoraireBase (arrondi au FCFA) MontantMajoration = MontantBase x TauxMajoration / 100 (arrondi au FCFA) MontantTotal = MontantBase + MontantMajoration

Arrondis : Math.Round(..., 0, MidpointRounding.AwayFromZero). Le taux horaire est arrondi à 2 décimales par la même méthode.

Exemple chiffré

Salarié : SalaireBase = 300 000 FCFA
Taux horaire = 300 000 / 173,33 = 1 730,61 FCFA/h

4. Rubrique dans le bulletin

Le recalcul du bulletin (méthode CalculerHeuresSupplementaires, appelée automatiquement par RecalculerSurGrilleExistante) fonctionne ainsi :

  1. Lecture de ParametresPaie.ActiverHeuresSupplementaires.
  2. Si désactivé OU si aucune ligne HS n'existe : la ligne de bulletin portant la rubrique canonique HeuresSupplementaires est supprimée.
  3. Si activé et au moins une ligne HS : somme des MontantTotal et écriture dans une ligne de gain unique sous la rubrique canonique HeuresSupplementaires.

Rubrique canonique

Une rubrique de type Gain portant le canonique RubriqueCanonique.HeuresSupplementaires doit exister et être active dans Paramétrage › Rubriques. Sans elle, la ligne de bulletin ne peut pas être créée. La propriété EnsureLine(RubriqueCanonique.HeuresSupplementaires, createIfMissing: true) gère la création/mise à jour.

Impact bruts et cotisations

  • Le total HS entre dans le Brut Fiscal et le Brut Social du bulletin (via la configuration de la rubrique).
  • Les cotisations (IPRES, CSS, IR, TRIMF, CFCE) sont recalculées sur ces nouveaux bruts à chaque RecalculerSurGrilleExistante.

5. Vérification et correction

5.1Consulter la collection HS du bulletin

Dans la vue détaillée du bulletin, l'onglet Heures supplémentaires liste les lignes HeureSupplementaire rattachées. Chaque ligne affiche type, heures, taux horaire, taux majoration, base, majoration et total.

5.2Corriger une ligne

Modifier TypeHS, NombreHeures ou TauxMajoration déclenche RecalculerMontants automatiquement sur la ligne. Après édition, enregistrer puis relancer le recalcul du bulletin pour mettre à jour la ligne de gain et les cotisations.

5.3Supprimer une ligne

Sélectionner la ligne HS dans la collection et la supprimer. Relancer le recalcul du bulletin pour que la ligne de gain soit mise à jour (ou retirée si plus aucune HS).

5.4Contrôle final avant validation

  • Chaque ligne HS a un MontantTotal cohérent avec heures x taux x majoration
  • La ligne de gain HeuresSupplementaires du bulletin reflète bien la somme des lignes
  • Le Brut Fiscal et le Brut Social incluent ce montant
  • Les cotisations ont été recalculées

6. Dépannage et FAQ

Le bouton "Ajouter HS" n'apparaît pas

Le module est désactivé. Aller dans Paramétrage › Paramètres de paie et cocher ActiverHeuresSupplementaires. Rafraîchir la vue du bulletin.

Message "Le bulletin doit être en Brouillon"

La saisie HS n'est acceptée que sur un bulletin brouillon (BulletinStatut.Brouillon). Pour un bulletin déjà validé, le repasser en brouillon si la procédure l'autorise, saisir les HS, puis revalider.

MontantTotal à 0 alors que les heures sont saisies

Le TauxHoraireBase est à 0 : vérifier que le salarié rattaché au bulletin a bien un SalaireBase > 0 sur sa fiche. Corriger la fiche salarié puis rééditer la ligne HS pour forcer le recalcul.

La ligne de gain "HeuresSupplementaires" n'apparaît pas dans le bulletin

Deux causes possibles :

  • Aucune rubrique active portant le canonique HeuresSupplementaires dans Paramétrage › Rubriques. La créer en type Gain.
  • Le module est désactivé : CalculerHeuresSupplementaires supprime la ligne au recalcul. Réactiver le module.

Je modifie une ligne HS mais le bulletin ne change pas

La modification d'une ligne HS recalcule la ligne elle-même, mais pas automatiquement le bulletin complet. Lancer Recalculer sur le bulletin pour mettre à jour la ligne de gain agrégée et les cotisations.

Erreur "Le nombre d'heures doit être entre 0,25 et 744"

La règle RuleRange(0.25, 744) protège contre les saisies aberrantes (744 h = 31 jours x 24 h, plafond mensuel théorique). Saisir une valeur dans cette plage.
