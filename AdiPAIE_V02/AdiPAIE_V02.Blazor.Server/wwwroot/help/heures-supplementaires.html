⏰ Heures supplémentaires — Guide complet

Ce module gère le calcul automatique des heures supplémentaires sur les bulletins, conformément aux taux légaux sénégalais (15 % jour ouvrable, 40 % nuit, 60 % dimanche/férié, 100 % nuit dimanche/férié). Les majorations sont intégrées au Brut Fiscal et Brut Social du bulletin.

⚙️ Étape 1 — Activer le module

Le module est désactivé par défaut. Pour l'activer :

1Aller dans Paramétrage → Paramètres de paie

2Onglet Heures supplémentaires

3Cocher Activer les heures supplémentaires

4Vérifier les taux de majoration

Pré-remplis avec les taux légaux sénégalais (modifiables si une convention collective prévoit mieux).

5Enregistrer

⚠️ Tant que le module est désactivé, le bouton Ajouter HS n'apparaît pas sur les bulletins et la collection HS est masquée.

➕ Étape 3 — Ajouter des HS sur un bulletin

1Ouvrir le bulletin du salarié (statut Brouillon)

2Cliquer sur ➕ Ajouter HS

3Renseigner le popup

  • Choisir le Type d'heure supplémentaire (jour, nuit, dimanche, nuit dimanche)
  • Saisir le Nombre d'heures
  • Le taux de majoration s'affiche automatiquement

4Cliquer OK

La ligne HS est créée et le bulletin est recalculé automatiquement.

5Répéter pour d'autres types d'heures

Plusieurs lignes possibles (1 par type), elles sont cumulées dans la rubrique HS.

6Valider le bulletin

✏️ Étape 4 — Modifier ou supprimer des HS

  • Les lignes HS sont visibles dans la collection Heures supplémentaires du bulletin.
  • Modifier le nombre d'heures ou le type directement dans la collection.
  • Pour supprimer : sélectionner la ligne HS et la supprimer.
  • Après toute modification, cliquer Recalculer pour mettre à jour le bulletin.

📊 Taux de majoration légaux (Sénégal)

Le Code du Travail sénégalais prévoit quatre niveaux :

TypeTauxQuand
Jour ouvrable15 %HS en journée, lundi–samedi
Nuit40 %HS de nuit (21h–5h), jours ouvrables
Dimanche / Jour férié60 %HS dimanche/férié en journée
Nuit dimanche / Férié100 %HS la nuit du dimanche/férié
💡 Modifiables dans Paramètres de paie → Heures supplémentaires. Si un taux est mis à 0, le système utilise automatiquement le taux légal par défaut.

🧮 Méthode de calcul détaillée

Taux horaire de base

Taux horaire = Salaire de base mensuel / 173,33 heures

Les 173,33 heures correspondent à la durée légale mensuelle : 40 heures × 52 semaines / 12 mois.

Calcul par ligne HS

Montant base = Nombre d'heures × Taux horaire
Montant majoration = Montant base × Taux majoration / 100
Montant total = Montant base + Montant majoration

Intégration au bulletin

Le total de toutes les lignes HS est regroupé dans une ligne de gain unique avec la rubrique canonique HeuresSupplementaires. Ce montant entre dans le Brut Fiscal et le Brut Social.

Exemple chiffré

Moussa DIOP — SB = 300 000 FCFA
Taux horaire = 300 000 / 173,33 = 1 731 FCFA/h

🎯 Cas d'usage concrets

Cas 1 — Audit nocturne en station-service

Modou (Auditeur) effectue 4 h d'audit de nuit à la station BANDIA un samedi soir. Saisie : Type = Nuit, Heures = 4. Majoration 40 %. Sur son bulletin du mois : ligne HS automatique.

Cas 2 — Inventaire de fin d'année (dimanche)

Coumba (Caissière) participe à l'inventaire annuel un dimanche, 6 h. Type = Dimanche, majoration 60 %. La rubrique HS s'ajoute à son brut.

Cas 3 — Garde de fin d'année (nuit du 31/12)

Mamadou (Sécurité) assure la garde dans la nuit du 31/12 (jour férié). 4 h en mode Nuit dimanche/férié, majoration 100 %.

📜 Règles métier

  • Les HS ne peuvent être ajoutées que sur un bulletin en Brouillon.
  • Le taux horaire est calculé automatiquement depuis le Salaire de base.
  • Les taux de majoration sont lus depuis Paramètres de paie.
  • Le total des HS est intégré comme un gain (rubrique canonique HeuresSupplementaires).
  • Les HS entrent dans le Brut Fiscal et le Brut Social.
  • Toutes les cotisations (IPRES, CSS, IR, TRIMF) sont recalculées en tenant compte des HS.
  • Si le module est désactivé, les lignes HS existantes sont ignorées au recalcul.

❓ FAQ et erreurs fréquentes

Bouton "Ajouter HS" invisible → le module est désactivé. Aller dans Paramètres de paie → Heures supplémentaires et cocher Activer.
Ligne HS à 0 dans le bulletin → vérifier qu'une rubrique avec le canonique HeuresSupplementaires existe et est active. Voir étape 2.
Taux horaire à 0 → le Salaire de base du salarié est à 0. Vérifier la fiche.
"Le bulletin doit être en Brouillon" → les HS ne peuvent être ajoutées que sur un bulletin non validé. Rouvrir le bulletin si nécessaire.
