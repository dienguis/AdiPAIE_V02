📅 Périodes de paie — Guide complet

La période de paie est le conteneur mensuel obligatoire de tous les bulletins. Elle structure le cycle paie : une seule période ouverte à la fois, ouverture, génération des bulletins, validation, déclarations sociales (IPRES, CSS, VRS, 1024) et clôture définitive.

📅 Étape 1 — Créer la période du mois

1Naviguer vers Paie → Périodes de paie

Cliquer sur + Nouveau.

2Renseigner les bornes du mois

Mois / Année
Ex. Mai 2026.
Date de début
1er jour du mois (ex. 01/05/2026).
Date de fin
Dernier jour du mois (ex. 31/05/2026).
Date de paiement prévue
Date virement bancaire (ex. 28/05/2026 à 17h).
Libellé
Auto-rempli (Paie Mai 2026) — modifiable.
Exemple : ELTON crée la période Mai 2026 le 25/04/2026, dates 01/05 → 31/05, virement programmé le 28/05.

🔓 Étape 2 — Ouvrir la période

1Cliquer sur Ouvrir la période

La période passe au statut Ouverte. À partir de là, les bulletins peuvent être créés.

⚠️ Une seule période peut être Ouverte simultanément. Si vous tentez d'ouvrir Juin sans avoir clôturé Mai, le système refuse l'opération.
💡 L'ouverture déclenche aussi : (1) le calcul des soldes congés du mois, (2) la consolidation des heures pointées du mois précédent, (3) la prise en compte des arrêts maladie validés.

📄 Étape 3 — Générer les bulletins (batch)

1Cliquer sur Générer tous les bulletins

Action en masse : le système crée un bulletin pour chaque salarié actif sur la période, en pré-remplissant :

  • Identité + matricule + service + catégorie
  • Salaire de base (depuis le contrat actif)
  • Indemnités fixes (transport, logement, etc.)
  • Échéances de prêts en cours du mois
  • Cotisations sociales (calculées automatiquement)

2Vérifier le rapport de génération

Affiche : nb créés / nb erreurs / nb skip. Erreurs typiques : salarié sans contrat actif, RIB manquant, catégorie non paramétrée.

Exemple : 247 salariés actifs → 245 bulletins créés, 2 erreurs (Coumba C. : pas de contrat actif ; Modou D. : RIB manquant). Le RH corrige et relance la génération uniquement pour ces deux.

✅ Étape 4 — Suivre l'avancement de validation

1Tableau de bord de la période

Depuis la fiche période, le RH voit en temps réel :

  • 📄 Bulletins en Brouillon : à valider
  • ✅ Bulletins Validés : prêts pour paiement
  • 📨 Bulletins Envoyés : PDF reçu par le salarié
  • 🔒 Bulletins Clôturés : verrouillés

2Filtrer et corriger

Cliquer sur le badge Brouillon pour voir la liste des bulletins encore en attente de validation. Pour le détail des étapes, voir le guide Bulletins.

🔒 Étape 6 — Clôturer la période

1Vérifier les pré-requis

  • Tous les bulletins doivent être au statut Validé/Envoyé/Clôturé.
  • Les déclarations sociales doivent avoir été exportées.
  • Les ordres de virement (OD) doivent être émis.

2Cliquer sur Clôturer la période

Une popup de confirmation s'affiche. Une fois cliqué, la période passe à Clôturée et aucun bulletin du mois ne peut plus être modifié.

⚠️ La clôture est quasi-irréversible. Une réouverture n'est possible que par l'administrateur système, et toujours documentée dans l'audit.
✅ Une fois la période Mai clôturée, vous pouvez ouvrir Juin et commencer le cycle suivant.

📊 Déclarations & exports détaillés

Boutons disponibles depuis la liste ou la fiche période :

📊 Générer bordereau IPRES : exporte le bordereau mensuel IPRES en Excel. Contient les cotisations Régime Général (salarié + employeur) et Régime Cadre (salarié + employeur) pour chaque salarié, avec totaux et sous-totaux.
📊 Générer bordereau CSS : exporte le bordereau mensuel CSS en Excel. Contient les cotisations Accident du Travail et Allocation Familiale (parts employeur uniquement) pour chaque salarié, avec totaux.
📊 Générer état VRS : exporte l'état mensuel VRS (Versement Retenue à la Source) en Excel. Colonnes : Matricule, Statut, Nom, BRUT, IR, TRIMF, CFCE, IPRES (RG/RC sal. + emp.), CSS (AT/AF), NET.
📊 Générer état 1024 : exporte la déclaration annuelle des salaires (DGID Sénégal) en Excel. Sélectionner les 12 périodes de l'année concernée.

Mode opératoire — Déclarations mensuelles

1Aller dans Paie → Périodes de paie

2S'assurer que tous les bulletins sont validés

3Sélectionner la période dans la liste

4Cliquer sur le bouton souhaité

(IPRES, CSS, VRS, ou 1024 pour le bilan annuel).

5Confirmer la période dans le popup

Pré-remplie avec la sélection. Le fichier Excel est téléchargé automatiquement.

🎯 Cas d'usage concrets

Cas 1 — Cycle mensuel standard

20/05 : RH crée la période Mai et l'ouvre.
21/05 : Génère 245 bulletins. 5 erreurs corrigées.
22-23/05 : Validation par RH + DAF.
26/05 : Exports IPRES/CSS/VRS. Envoi banque.
28/05 : Virements effectués. Bulletins envoyés par mail.
02/06 : Clôture définitive de Mai. Ouverture Juin.

Cas 2 — Régularisation rétroactive

En juin, on découvre une erreur de prime sur le bulletin Mai d'un salarié. Comme Mai est clôturée, on ne peut pas modifier directement le bulletin de mai. Solution : ajouter une régularisation sur le bulletin de Juin (rubrique RÉGUL_MOIS_PRECEDENT) qui ajuste le net.

Cas 3 — Déclaration annuelle 1024

Fin janvier 2027, la DGID demande la déclaration annuelle 1024 pour 2026. RH va dans Périodes de paie, sélectionne les 12 périodes Jan-Déc 2026, clique Générer état 1024. Excel obtenu prêt à déposer sur la plateforme DGID.

❓ FAQ et erreurs fréquentes

"Une période est déjà ouverte, fermez-la avant d'en ouvrir une autre"
→ Aller sur la période en cours et cliquer sur Clôturer. Vérifier que tous les bulletins sont au moins Validés.
"Aucun bulletin valide trouvé" (lors d'un export)
→ Vérifier que les bulletins du mois sont bien validés (pas en Brouillon). Filtrer la liste par statut.
Montants IPRES/CSS à 0 dans le bordereau
→ Vérifier que les rubriques IPRES_RG, IPRES_RC, CSS_AccidentTravail, CSS_AllocationFamiliale sont bien paramétrées avec les bons taux dans Paramétrage → Rubriques.
"Période impossible à clôturer : 3 bulletins en brouillon"
→ Le système liste les bulletins concernés. Les valider ou les supprimer (si salarié sorti).
💡 Comment réouvrir une période clôturée par erreur ? Action réservée à l'administrateur : Administration → Périodes → Sélectionner → Forcer la réouverture. Une justification écrite est obligatoire et l'action est tracée dans l'audit.
