Periodes de paie

Flux

  1. Creer une periode (Mois/Annee)
  2. Ouvrir → statut Ouverte
  3. Generer les bulletins
  4. Cloturer apres validation de tous les bulletins

Regles

  • Une seule periode Ouverte a la fois
  • Impossible de creer un bulletin sans periode Ouverte
  • Cloturer bloque toute modification des bulletins du mois

Declarations et exports

Depuis la liste des periodes de paie, plusieurs boutons d'export sont disponibles :

Boutons disponibles

Generer etat 1024 : exporte la declaration annuelle des salaires (DGID Senegal) en Excel. Selectionner la ou les periodes concernees.
Generer etat VRS : exporte l'etat mensuel VRS (Versement Retenue a la Source) en Excel. Colonnes : Matricule, Statut, Nom, BRUT, IR, TRIMF, CFCE, IPRES (RG/RC salarie et employeur), CSS (AT/AF), NET.
Generer bordereau IPRES : exporte le bordereau mensuel IPRES en Excel. Contient les cotisations Regime General (salarie + employeur) et Regime Cadre (salarie + employeur) pour chaque salarie, avec totaux et sous-totaux.
Generer bordereau CSS : exporte le bordereau mensuel CSS en Excel. Contient les cotisations Accident du Travail et Allocation Familiale (parts employeur) pour chaque salarie, avec totaux.

Mode operatoire — Declarations sociales

  1. Aller dans Paie → Periodes de paie
  2. S'assurer que tous les bulletins du mois sont valides
  3. Selectionner la periode dans la liste
  4. Cliquer sur le bouton souhaite :
    • Generer bordereau IPRES pour la declaration IPRES
    • Generer bordereau CSS pour la declaration CSS
    • Generer etat VRS pour la declaration fiscale
  5. Confirmer la periode dans le popup (pre-remplie)
  6. Le fichier Excel est telecharge automatiquement

Important : seuls les bulletins valides, envoyes ou clotures sont pris en compte dans les declarations. Les bulletins en brouillon sont ignores.

Erreurs frequentes

"Aucun bulletin valide trouve" → Verifier que les bulletins du mois sont bien valides (pas en Brouillon).
Montants IPRES/CSS a 0 → Verifier que les rubriques IPRES_RG, IPRES_RC, CSS_AccidentTravail, CSS_AllocationFamiliale sont bien parametrees avec les bons taux.
