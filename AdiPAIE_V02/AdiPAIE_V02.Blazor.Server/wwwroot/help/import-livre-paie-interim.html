📥 Import du Livre de Paie Intérimaire — Guide complet

Cette fonctionnalité permet de charger chaque mois le fichier Excel de facturation envoyé par chaque société d'intérim, contenant le coût réel TTC de chaque intérimaire. Une fois importé, le dashboard Tableau N°11 — Coût Réel Intérimaires compare automatiquement le coût réel facturé avec le coût théorique du contrat.

📌 Où dépose-t-on le fichier ?
On NE dépose PAS le fichier sur un dossier serveur. L'import se fait entièrement dans l'application via le wizard d'import (menu Intérimaires → Charger livre de paie). Le fichier reste sur votre poste, on l'upload directement dans le navigateur. Il est ensuite stocké dans la base de données via les entités BulletinInterim et ImportBulletinInterimBatch.

📥 Modèle (.xlsx)

📥 Étape 1 — Télécharger le modèle (référence)

1Cliquer sur le bouton « Modèle (.xlsx) » ci-dessus

Le fichier Modele_LivrePaieInterim.xlsx est téléchargé sur votre poste.

2Communiquer le format aux sociétés d'intérim

Si vous travaillez avec une nouvelle société d'intérim, transmettez-lui ce modèle pour qu'elle envoie ses factures dans le bon format. Le système sait néanmoins lire des variantes proches (mapping fuzzy par titre de colonne).

📧 Étape 2 — Recevoir et vérifier la facture mensuelle

1Recevoir le fichier .xlsx de la société d'intérim

Chaque mois, chaque société d'intérim partenaire envoie un fichier Excel contenant le détail des intérimaires affectés à ELTON et le coût TTC à payer. Sauvegarder ce fichier sur votre poste.

2Vérification rapide avant import

Avant d'importer, ouvrez le fichier dans Excel et vérifiez :

  • La période est bien le mois attendu (titre du fichier ou colonne dédiée)
  • La société émettrice est claire
  • Les colonnes Débours, Commission agence, Montant HT, TVA, TTC sont remplies
  • Les totaux en bas du fichier sont cohérents (somme par colonne)

📤 Étape 3 — Importer dans SunuPaie (wizard 4 étapes)

1Aller dans le menu Intérimaires

Cliquer sur Intérimaires → Charger livre de paie. Le wizard d'import s'ouvre.

2Étape 1 du wizard — Sélection de la période et de la société

  • Année : ex 2026
  • Mois : 1 à 12 (ex 3 pour mars)
  • Société d'intérim émettrice : choisir parmi les sociétés enregistrées

Si la société n'apparaît pas, créer d'abord la fiche dans Intérimaires → Sociétés d'intérim.

3Étape 2 du wizard — Upload du fichier

Cliquer sur Choisir le fichier et sélectionner le .xlsx reçu de la société d'intérim. Le système parse le contenu sans encore l'enregistrer en base.

4Étape 3 du wizard — Preview du résultat

Le système affiche un résumé :

  • X bulletins OK (matricule existant trouvé)
  • Y fiches Intérimaire à créer auto (matricule inconnu)
  • Z lignes Prestataire (cas spécifique)
  • Total TTC du lot (le montant que vous allez payer)

Si un batch existe déjà pour cette (Année, Mois, Société), un avertissement apparaît : "Au commit, l'ancien sera remplacé". Cocher Écraser pour confirmer.

5Étape 4 du wizard — Confirmation et commit

Cliquer sur Confirmer l'import. Le système :

  • Crée 1 lot d'import (ImportBulletinInterimBatch)
  • Crée N bulletins (BulletinInterim)
  • Crée les fiches Interimaire manquantes (Nom, Prénom, Matricule, Société, Fonction)
  • Affiche un rapport final avec liens vers les fiches créées auto

✅ Étape 4 — Compléter les fiches créées automatiquement

⚠️ Action RH obligatoire : les fiches Intérimaire créées automatiquement contiennent uniquement Matricule + Nom + Prénom + Société + Fonction. Le RH doit ensuite compléter les champs additionnels (Date de naissance, CNI, Adresse, Téléphone, Email) et créer le contrat intérimaire correspondant.

1Récupérer la liste des fiches créées

Dans Intérimaires → Lots d'import, ouvrir le batch que vous venez d'importer. La colonne Nb fiches Intérimaire créées auto indique combien de fiches sont à compléter.

2Filtrer les bulletins avec statut "Fiche créée auto"

Dans la liste des Bulletins intérim, filtrer sur Statut = Fiche créée auto. Ces lignes pointent vers les intérimaires nouvellement créés.

3Compléter chaque fiche + créer son contrat

Pour chaque intérimaire dans cette liste, ouvrir sa fiche et :

  • Renseigner Date de naissance, CNI, Adresse, Téléphone, Email
  • Créer le contrat (Contrats intérimaires → Nouveau)
  • Renseigner Site, Unité organisationnelle, Date début, Taux journalier

📊 Étape 5 — Consulter le dashboard Coût Réel

Une fois l'import effectué, le Tableau de Bord N°11 — Coût Réel Intérimaires affiche automatiquement les données du mois importé :

  • KPIs : Total TTC mois, Cumul YTD, Multiplicateur Brut→TTC, Coût moyen par intérimaire
  • Comparaison Contrat vs Réel : pour chaque intérimaire, écart entre le coût théorique (TauxJournalier × 22) et le TTC facturé
  • Top 10 coûts : les 10 intérimaires les plus chers du mois
  • Décomposition : Brut / Charges / Commission / TVA
  • Évolution 12 mois : courbe TTC pour détecter les tendances

🎯 Cas particuliers

Cas A — PRESTATAIRE indépendant

Si la cellule "N° matricule" contient le texte PRESTATAIRE, le système considère qu'il s'agit d'un prestataire indépendant mis à disposition par la société d'intérim, sans fiche Intérimaire à créer :

  • Le BulletinInterim est créé avec Interimaire = null
  • Le statut est Prestataire
  • Le coût TTC est inclus dans le total du batch

Cas B — Matricule inconnu (intérimaire pas encore dans le SI)

Si le matricule existe dans le fichier mais aucune fiche Intérimaire n'a ce matricule, le système :

  • Crée automatiquement la fiche avec Matricule + Nom + Prénom + Société + Fonction
  • Le BulletinInterim a le statut Fiche créée auto
  • Le RH doit ensuite compléter cette fiche et créer le contrat (cf. Étape 4)

Cas C — Réimport du même mois (correction)

Si vous réimportez le même mois pour la même société (ex correction d'erreur de facturation), le système détecte le batch existant et propose :

  • Annuler : ne rien faire
  • Écraser : supprime l'ancien batch + ses bulletins, puis recrée à partir du nouveau fichier

L'écrasement est irréversible mais conserve les fiches Intérimaire créées auto précédemment (juste les bulletins sont remplacés).

❓ FAQ

QuestionRéponse
Le fichier Excel a un format légèrement différent (colonnes renommées). Le mapping est fuzzy : tant que le titre contient le mot-clé attendu (ex "matricule", "debours", "ttc"), c'est reconnu. Si une colonne obligatoire est introuvable, le preview affiche une erreur explicite.
Je ne trouve pas le menu "Charger livre de paie". Vérifier votre rôle (Administrators, RH_Manager, RH ou DAF). Le menu est dans Intérimaires → Charger livre de paie.
Combien de temps prend l'import ? ~5 secondes pour 250 lignes. La majorité du temps est passée sur le commit transactionnel (création des fiches manquantes + bulletins).
Comment annuler un import ? Aller dans Intérimaires → Lots d'import, ouvrir le batch concerné, cliquer sur Delete. La suppression cascade détruit les bulletins associés. Les fiches Intérimaire créées auto sont conservées (à supprimer manuellement si besoin).
Combien d'années conserve-t-on l'historique ? Tout est conservé sans purge automatique. Permet l'analyse historique sur 5+ ans dans le dashboard Coût Réel.
