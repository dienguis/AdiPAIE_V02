Import Livre de Paie Interim (Excel) - Guide RH

Ce guide décrit l'import mensuel du fichier Excel de facturation envoyé par chaque société d'intérim partenaire d'ELTON. Ce fichier contient le coût TTC réel de chaque intérimaire affecté sur site. Une fois importé, il alimente le dashboard N°11 Coût Réel Intérim qui compare le coût facturé au coût théorique du contrat. Le format attendu est un classeur 53 colonnes, dont un bloc facturation obligatoire (Débours, Commission agence, Montant HT, TVA, TTC).

1. Vue d'ensemble du processus

Pourquoi importer

Chaque société d'intérim facture ELTON chaque mois pour les intérimaires mis à disposition. Le fichier Excel reçu contient, pour chaque intérimaire, le détail salarial et surtout la ligne de facturation (Débours, Commission, HT, TVA, TTC). L'import permet de :

  • Enregistrer le coût réel TTC payé à la société d'intérim
  • Comparer ce coût au coût théorique calculé depuis le contrat (TauxJournalier x jours)
  • Alimenter le dashboard N°11 Coût Réel Intérim (KPI, top 10, évolution 12 mois)
  • Créer automatiquement les fiches Intérimaire manquantes (nouvelles arrivées)

Les entités créées à l'import

ImportBulletinInterimBatch
Le lot d'import. Un lot = un fichier = une société d'intérim x un mois x une année. Un index unique interdit deux lots pour le même triplet.
BulletinInterim
Une ligne par intérimaire du fichier. Porte le détail salarial et le bloc facturation. Rattaché au lot et (si matricule connu) à la fiche Intérimaire.
Interimaire (créé si besoin)
Si le matricule n'existe pas encore, une fiche minimale est créée automatiquement avec Matricule, Nom, Prénom, Société, Fonction. Le RH complète ensuite les champs manquants et crée le contrat.

Statuts d'un BulletinInterim

StatutSignification
Importé OKMatricule retrouvé dans la base, bulletin rattaché à sa fiche Intérimaire existante
Fiche créée autoMatricule inconnu, fiche Intérimaire minimale créée. Le RH doit la compléter (voir section 6)
PrestataireMatricule = PRESTATAIRE (ou PREST). Pas de fiche Intérimaire créée, l'Interimaire reste null. Le coût TTC est néanmoins inclus dans le total
ErreurLigne non interprétable

2. Télécharger le modèle 53 colonnes

Le classeur Modele_LivrePaieInterim.xlsx reflète le format attendu. Il contient la ligne d'en-tête de référence et deux lignes d'exemple (un intérimaire normal, un prestataire).

Télécharger Modele_LivrePaieInterim.xlsx

Mapping fuzzy : le système identifie chaque colonne par son titre d'en-tête, pas par sa position. Les variantes de casse, d'accents et d'espaces sont tolérées (ex. "DEBOURS", "Débours", "debours" sont tous reconnus). La ligne d'en-tête est détectée automatiquement dans les 30 premières lignes du classeur en cherchant le mot "matricule".

3. Lancer l'import (création du lot)

A faire une fois par mois et par société d'intérim, dès réception de la facture Excel.

3.1Préparer le fichier reçu

Enregistrer le .xlsx reçu de la société d'intérim sur le poste. Ouvrir rapidement le fichier dans Excel et vérifier :

  • La période couverte est bien le mois attendu
  • La société émettrice est claire (en-tête ou nom du fichier)
  • Les colonnes Débours, Commission agence, Montant HT, TVA, TTC sont remplies
  • Les totaux en bas du fichier sont cohérents (somme par colonne)

3.2Ouvrir le wizard d'import

Menu : Intérimaires › Lot d'import - Bulletin intérim, puis bouton "Charger livre de paie" dans la barre d'actions.

Le wizard d'import s'ouvre dans un nouvel onglet.

3.3Renseigner période et société

  • Année : ex. 2026
  • Mois : 1 à 12 (ex. 3 pour mars)
  • Société d'intérim émettrice : choisir parmi les sociétés enregistrées

Si la société n'apparaît pas dans la liste, créer d'abord sa fiche dans Intérimaires › Sociétés d'intérim avant de reprendre le wizard.

3.4Uploader le fichier et lancer le preview

Cliquer sur "Choisir le fichier" et sélectionner le .xlsx reçu. Le système parse le contenu sans rien écrire en base et affiche un résumé :

  • X bulletins OK (matricule retrouvé)
  • Y fiches Intérimaire à créer auto (matricule inconnu)
  • Z lignes Prestataire (matricule = PRESTATAIRE)
  • Total TTC du lot (montant total à payer)

Si un lot existe déjà pour ce triplet (Année, Mois, Société), un avertissement "Batch déjà existant" apparaît. Voir section 5 pour l'écrasement.

3.5Confirmer le commit

Cliquer sur "Confirmer l'import". Le système, en une seule transaction :

  1. Crée le lot ImportBulletinInterimBatch
  2. Crée N BulletinInterim rattachés au lot
  3. Crée les fiches Interimaire manquantes (Matricule, Nom, Prénom, Société, Fonction)
  4. Snapshotte le MatriculeOriginal sur chaque bulletin (traçabilité si renommage ultérieur)
  5. Affiche le rapport final avec liens vers les fiches créées auto

4. Vérification du lot importé

4.1Ouvrir la fiche du lot

Menu : Intérimaires › Lot d'import - Bulletin intérim. Ouvrir le lot que vous venez de créer (identifié par Année, Mois, Société).

Contrôler :

  • Total TTC du lot = total facture reçue (contrôle par rapprochement direct)
  • Nombre de bulletins = nombre de lignes dans le fichier source
  • Nb fiches Intérimaire créées auto : indique combien de fiches sont à compléter

4.2Parcourir les bulletins par statut

Dans la liste des bulletins intérim rattachés au lot, filtrer sur :

  • Statut = Importé OK : rien à faire, bulletins rattachés à leur fiche existante
  • Statut = Fiche créée auto : à traiter en section 6
  • Statut = Prestataire : rien à faire, le TTC est bien pris en compte dans le total
  • Statut = Erreur : ligne non interprétable, à investiguer

4.3Contrôler le dashboard N°11

Ouvrir Tableaux de bord › N°11 Coût Réel Intérim. Les données du mois importé apparaissent immédiatement :

  • KPI Total TTC mois, cumul YTD, multiplicateur Brut vers TTC, coût moyen
  • Comparaison contrat vs réel ligne par ligne
  • Top 10 des coûts du mois
  • Décomposition Brut / Charges / Commission / TVA
  • Évolution 12 mois

Si un intérimaire a un écart contrat vs réel important, vérifier son contrat (TauxJournalier à jour ?) et le détail de sa facturation sur le bulletin.

5. Correction et ré-import

Cas d'usage : la société d'intérim a envoyé une facture erronée et renvoie un fichier corrigé pour le même mois.

5.1Relancer le wizard avec le nouveau fichier

Reprendre la procédure section 3 avec le fichier corrigé, en indiquant le même triplet Année, Mois, Société que le lot déjà présent.

Au preview, le système affiche l'avertissement "Batch déjà existant". Trois choix :

  • Annuler : rien n'est modifié, le lot existant reste en place
  • Écraser : cocher la case "Écraser le batch existant" avant Commit

5.2Effet de l'écrasement

A la confirmation, le système :

  1. Supprime l'ancien lot et tous ses bulletins
  2. Flushe la transaction pour libérer l'index unique
  3. Crée le nouveau lot et les nouveaux bulletins à partir du fichier corrigé

Les fiches Intérimaire créées auto au premier import sont conservées. Seuls les bulletins sont remplacés. L'opération est irréversible.

5.3Supprimer un lot sans le remplacer

Pour annuler purement et simplement un import erroné, ouvrir le lot dans Intérimaires › Lot d'import - Bulletin intérim, puis Supprimer. La suppression en cascade détruit tous les bulletins rattachés. Les fiches Intérimaire créées auto restent en base (à supprimer manuellement si elles sont inutiles).

6. Compléter les fiches créées auto

Action RH obligatoire : les fiches créées automatiquement par l'import ne contiennent que Matricule, Nom, Prénom, Société et Fonction. Les autres champs (date de naissance, CNI, adresse, téléphone, email) et le contrat intérimaire doivent être complétés manuellement.

6.1Récupérer la liste des fiches à compléter

Dans la fiche du lot (section 4.1), consulter Nb fiches Intérimaire créées auto. Ou filtrer la liste des bulletins sur Statut = Fiche créée auto pour voir chaque bulletin et sa fiche cible.

6.2Compléter chaque fiche Intérimaire

Pour chaque intérimaire, ouvrir sa fiche et renseigner :

  • Date de naissance, CNI, adresse, téléphone, email
  • Tout autre champ requis par la politique RH

6.3Créer le contrat intérimaire

Dans Intérimaires › Contrats intérimaires › Nouveau, créer le contrat correspondant :

  • Site d'affectation
  • Unité organisationnelle
  • Date de début (et date de fin si CDD)
  • Taux journalier théorique (base de calcul du coût théorique dans le dashboard N°11)

Sans ce contrat, l'écart contrat vs réel n'est pas calculable pour l'intérimaire concerné dans le dashboard N°11.

7. Dépannage et FAQ

Le preview affiche "Colonne obligatoire introuvable"

Un titre de colonne obligatoire (Matricule, Noms, Prénoms, Débours, Commission, TVA, TTC) n'a pas été reconnu, même en fuzzy. Ouvrir le fichier Excel et vérifier que le libellé contient bien le mot-clé attendu (ex. "ttc", "debours"). Au besoin, renommer la colonne dans le fichier et relancer l'import.

Le preview détecte 0 ligne alors que le fichier en contient

La ligne d'en-tête n'a pas été trouvée dans les 30 premières lignes du classeur. Vérifier qu'au moins une cellule de l'en-tête contient le mot "matricule". Supprimer les lignes vides ou décoratives placées au-dessus de l'en-tête si elles dépassent 30 lignes.

Je ne vois pas le bouton "Charger livre de paie"

Permission manquante sur le rôle de l'utilisateur. Le bouton n'est visible que pour les rôles habilités (Administrators, RH_Manager, RH, DAF). Faire :

  1. Login Admin
  2. Menu Paramètres de paie › Init. rôles GRH, clic
  3. Déconnexion/reconnexion de l'utilisateur concerné

Le commit échoue : "Batch déjà existant"

Un lot existe déjà pour le même triplet Année, Mois, Société. Soit c'est un doublon à ignorer (annuler), soit c'est une correction : cocher "Écraser le batch existant" avant de valider. L'index unique de la base interdit deux lots pour le même triplet.

Un montant est manifestement faux (ex. 25 000 000 au lieu de 25 000)

L'import lit la valeur numérique brute (GetNumber()) pour éviter les confusions de séparateur décimal (virgule vs point). Si une valeur reste fausse, c'est que la cellule contient du texte ou une formule non évaluée. Ouvrir le fichier, forcer la valeur en nombre et relancer.

Une ligne "Total" du fichier a été importée comme bulletin

Normalement, les lignes dont le matricule vaut "total" (insensible à la casse) ou qui sont vides sont ignorées. Si une ligne de total passe quand même, c'est que son matricule contient autre chose (ex. "Total général"). Modifier le fichier et relancer, ou supprimer le bulletin parasite depuis la fiche du lot.

Un intérimaire a un gros écart contrat vs réel dans le dashboard N°11

Trois causes à vérifier dans l'ordre :

  1. Son contrat intérimaire n'a pas de TauxJournalier à jour
  2. Il n'a pas de contrat du tout (fiche créée auto mais pas de contrat associé - cf. section 6.3)
  3. La facture reçue est effectivement anormale : contacter la société d'intérim

Un bulletin a le statut "Prestataire" mais c'est en fait un intérimaire normal

Le matricule dans le fichier commence par "PRESTATAIRE" ou "PREST". Corriger le matricule dans le fichier Excel (mettre le vrai matricule) et ré-importer en écrasant le lot (section 5).
