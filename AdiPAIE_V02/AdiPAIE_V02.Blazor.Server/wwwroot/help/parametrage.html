Paramétrage - Guide Admin

Ce guide décrit la configuration structurante de SunuPaie : référentiel des rubriques et de leurs types, barèmes fiscaux (IR progressif DGID, TRIMF mensuel et annuel), cotisations sociales (IPRES RG et RC, CSS, CFCE), paramètres de paie globaux (abattement IMAB, réduction familiale, mode de calcul CFCE, mode bulletin congé), initialisation des rôles GRH et configuration SMTP / Microsoft Graph pour les notifications. Toute modification impacte les bulletins recalculés après la mise à jour : à faire en début d'exercice ou sur instruction officielle (loi de finances, réforme sociale).

2. Rubriques et types de rubrique

Une Rubrique est une ligne de bulletin (gain, retenue ou information). Chaque rubrique est rattachée à un RubriqueTypeRef qui porte les défauts métier (type de calcul, brut fiscal, brut social, ordre d'impression, section).

2.1Ouvrir la liste des rubriques

Menu : Paramétrage › Rubriques.

Les rubriques officielles ELTON sont créées automatiquement par le seed du référentiel si la case Activer le seed du référentiel paie est cochée sur Paramètres de paie au premier démarrage. Le seed est idempotent : ne crée que ce qui manque.

2.2Champs clés d'une rubrique

Code
Identifiant court, MAJUSCULES, 2 à 20 caractères A-Z 0-9 _. Unique en base. Exemples : SAL_BASE, IPRES_RG, TRIMF, CONGE_PAYE, ICCP.
Libelle
Texte affiché sur le bulletin. Normalisé en Title Case français.
Canonique
Rôle technique utilisé par le moteur de calcul (SalaireDeBase, IPRES_RG, TRIMF, RemboursementPret, RemboursementAvance, etc.). Doit rester unique en base. Ne jamais le modifier après mise en production.
TypeRef
Type de rubrique obligatoire. Son changement applique automatiquement les défauts du type (TypeCalcul, BrutFiscal, BrutSocial, ordre, section). Action Reprendre défauts du type disponible pour les reprendre à tout moment.
TypeCalcul
Gain, Retenue ou Information.
BrutFiscal
Oui : la rubrique entre dans la base IR / TRIMF.
BrutSocial
Oui : la rubrique entre dans la base IPRES / CSS.
OrdreAffichage
Ordre dans le bulletin imprimé. Trier par pas de 10 (10, 20, 30…) pour pouvoir insérer entre.
Actif
Non : la rubrique disparaît des listes de saisie mais reste utilisable pour les bulletins historiques. On ne supprime jamais une rubrique déjà utilisée (intégrité référentielle).
SectionImpression
Alias calculé sur TypeRef.Groupe.Libelle. Regroupe les rubriques sur le PDF du bulletin.
Deux rubriques distinctes servent le congé : CONGE_PAYE (versée quand le salarié part physiquement en congé) et ICCP (indemnité compensatrice, versée pour un reliquat ou un départ sans prise de congé). Même traitement cotisations (IPRES / CSS / IR / TRIMF / CFCE), tracées séparément pour le reporting.

3. Barèmes IR et TRIMF

Les barèmes sont historisés par code et par dates (DateDebut / DateFin). Un ancien bulletin recalculé utilise le barème en vigueur à sa date. Mettre à jour chaque année après publication de la loi de finances.

3.1Barème IR (DPP annuel)

Menu : Paramétrage › Barèmes IR.

Entité BaremeIR : un code unique (ex. IR_DPP_2026), un drapeau Actif, une plage de validité, et une collection de BaremeIRTranche.

Chaque tranche porte :

  • MontantMin et MontantMax (bornes incluses)
  • Taux en pourcentage

Règles : MontantMin <= MontantMax, triplet (barème + Min + Max) unique. Les tranches couvrent la plage complète sans trou.

Le code du barème IR actif est référencé par ParametresPaie.CodeBaremeIR_Annuel (défaut IR_DPP_{YYYY}, résolu à l'exécution avec l'année).

3.2Barèmes TRIMF (mensuel et annuel)

Menu : Paramétrage › Barèmes TRIMF.

Deux codes distincts sont référencés par ParametresPaie :

  • CodeBaremeTRIMF_Mensuel (défaut TRIMF_{YYYY}) - utilisé sur les bulletins mensuels
  • CodeBaremeTRIMF_Annuel (défaut TRIMF_AN_{YYYY}) - utilisé pour la régularisation annuelle

Les tokens {YYYY} et {YY} sont remplacés à la volée par l'année résolue (année courante par défaut). Permet de garder un paramétrage stable d'une année à l'autre.

4. Taux de cotisations (IPRES, CSS, CFCE)

Les cotisations sociales sénégalaises sont portées par des Rubrique de type Retenue avec BrutSocial = Oui. Les taux sont stockés directement sur la rubrique (part salariale / part patronale) et sur les champs plafond propres à chaque régime. Ne les modifier que sur instruction officielle.

5. Paramètres de paie (IR, CFCE, modèle bulletin)

Menu : Paramétrage › Paramètres de paie. Un seul enregistrement est autorisé (singleton soft : la sauvegarde d'un second enregistrement est bloquée).

5.1Onglet Général

ActiverSeedReferentiel
Coche avant le 1er démarrage pour initialiser le référentiel ELTON (conventions, catégories, échelons, plan comptable, rubriques, barèmes). Idempotent, ne crée pas de salariés démo. Décocher après init.
ModeBulletinConges
BulletinUnique (défaut) : la ligne CONGE_PAYE s'ajoute au bulletin mensuel. BulletinSepare : un bulletin de congé distinct est émis. Modifiable à tout moment, prend effet sur les bulletins générés après le changement.
Signataire (nom, fonction, logo, signature, cachet)
Images et libellés imprimés en pied du bulletin PDF et des attestations.

5.2Onglet Fiscalité

CodeBaremeTRIMF_Mensuel / CodeBaremeTRIMF_Annuel
Patterns de code avec tokens {YYYY} / {YY}. Résolus à l'exécution via ResolveCodeTRIMFMensuel / ResolveCodeTRIMFAnnuel.
CodeBaremeIR_Annuel
Pattern de code pour le barème IR DPP (défaut IR_DPP_{YYYY}).
R_IR_TronquerBaseAuxMille
Si Oui : la base IR est tronquée au millier inférieur avant application du barème (défaut Oui, conforme DGID).
ModeBaseCFCE
AvecAvantagesNature (défaut) : base CFCE = brut fiscal complet, aligné sur IR / TRIMF. SansAvantagesNature : exclut les avantages en nature. Changement effectif sur les bulletins recalculés après modification.
R_IR_Abattement_TauxPercent (IMAB)
Taux d'abattement professionnel en pourcentage, saisi en valeur brute (ex. 30 pour 30 %). Défaut Sénégal : 30 %.
R_IR_Abattement_PlafondAnnuel / PlafondMensuel
Plafonds de l'abattement. Défaut Sénégal : 900 000 FCFA annuel, 75 000 FCFA mensuel.
IR_Regularisation_FinAnnee
Si Oui : régularisation IR en fin d'exercice sur le bulletin de décembre (défaut Oui).
IR_Regularisation_MoisDepart
Si Oui : régularisation IR sur le bulletin du mois de départ d'un salarié (défaut Oui).
R_IR_ReductionFamille_Pourcentage / MinParPart_Annuel / MaxParPart_Annuel
Paramètres de la réduction familiale par part. Pourcentage saisi en valeur brute. Fallback utilisé quand le barème par parts n'est pas défini.

ModeleAuto_Defaut_Sursalaire / PrimeTransport / AvantageVehicule
Montants par défaut injectés dans le modèle à la création.

6. Initialisation des rôles GRH

6.1Action "Init. rôles GRH"

Sur la vue Détail de Paramètres de paie, le bouton "Init. rôles GRH" (contrôleur InitialiserRolesGRHController) crée les 8 rôles standards :

  • Employe
  • Responsable
  • AssistantRH
  • AssistantCommercial
  • RH
  • DAF
  • DG (Directeur Général)
  • Comptable

L'action est idempotente : les rôles existants ne sont jamais écrasés, les permissions sont ajoutées sans doublon. La logique est portée par RolesGRHInitializer.Initialize, réutilisée au démarrage de l'application (DatabaseUpdate.Updater).

Résultat : un toast indique le nombre de rôles créés et de permissions ajoutées. Relancer l'application pour que les droits soient actifs.

Pour qu'un salarié voie Mon espace, son compte utilisateur doit porter le rôle Employe et son champ Email doit correspondre à son UserName.

7. SMTP, Microsoft Graph et notifications

Les paramètres de messagerie sont portés par Paramètres de paie, onglet Messagerie. Deux fournisseurs sont supportés via EmailProviderKind : Smtp (défaut) ou Graph (Microsoft Graph API).

7.1Activer la messagerie

Cocher EmailActif. Si décoché, la fabrique CreateEmailSender lève une exception explicite.

7.2Mode SMTP

SmtpHost
Serveur SMTP. Défaut smtp.office365.com.
SmtpPort
Port TCP (plage 1-65535). Défaut 587.
SmtpUseSsl
Active TLS/SSL. Défaut Oui.
SmtpUserName / SmtpPassword
Identifiants du compte d'envoi. Pour Gmail / Office 365, utiliser un App Password dédié avec 2FA activée.
MailFromAddress / MailFromDisplayName
Adresse et nom affiché de l'expéditeur. Défaut nom "Service Paie".
MailReplyTo / MailBccDefault
Reply-to par défaut et liste BCC (séparés par ; ou ,).

7.3Mode Microsoft Graph

Choisir EmailProviderKind = Graph et renseigner :

  • GraphTenantId - Tenant ID Azure AD
  • GraphClientId - Client ID de l'application enregistrée
  • GraphClientSecret - Secret client (masqué)
  • GraphFromUserUpn - UPN de l'expéditeur. Si vide, retombe sur MailFromAddress.

L'application doit avoir la permission Mail.Send en Application permissions sur Azure AD.

7.4Alertes RH et notifications

DelaiAlertAttestationJours
Délai en jours avant qu'une demande "Soumise" génère une alerte RH. 0 à 365, défaut 2. 0 désactive les alertes.
EmailsRHAlertes
Un ou plusieurs destinataires RH, séparés par ;.
HeureEnvoiAlertes
Heure de déclenchement du service d'alertes (0-23). Défaut 8.
EmailDAF
Email du DAF pour les notifications d'ordre de mission approuvé.
EmailsComptable
Un ou plusieurs comptables pour les notifications de décaissement, séparés par ;.

7.5Templates Word GRH

Les templates .docx suivants sont uploadés directement sur Paramètres de paie, onglet GRH - Templates :

  • Attestation de travail
  • Attestation de congés
  • Certificat d'emploi
  • Cessation de paiement
  • Entretien annuel
  • Bilan social
  • Ordre de mission
  • État de frais de mission
  • Attestation de formation
  • Contrat CDI / CDD / stage

Les marqueurs {{...}} dans les templates sont substitués à la génération.

8. Dépannage et FAQ

"Un seul enregistrement Paramètres de paie est autorisé"

La sauvegarde est bloquée par OnSaving si un second enregistrement existe. Supprimer le doublon ou éditer l'enregistrement existant.

"La messagerie n'est pas activée dans Paramètres de paie"

Cocher EmailActif. Puis vérifier que SmtpHost et MailFromAddress sont renseignés (mode SMTP), ou que les champs Graph (TenantId / ClientId / ClientSecret) sont complets (mode Graph).

Test email : authentification refusée (Gmail / Office 365)

Créer un App Password dédié sur le compte d'envoi et activer la 2FA. Le mot de passe principal est refusé par ces fournisseurs pour SMTP.

Cotisation IPRES à 0 sur le bulletin

Vérifier que la rubrique IPRES_RG (et IPRES_RC pour les cadres) existe, est Active, porte BrutSocial = Oui et a les bons taux (part salariale / part patronale).

"Cette rubrique ne peut pas être supprimée"

Elle est référencée par des bulletins. L'intégrité référentielle bloque la suppression. Passer Actif = Non pour la retirer des listes de saisie sans casser l'historique.

Le menu "Soldes de congés" (ou autre menu GRH) n'apparaît pas

Permission manquante sur le rôle. Lancer Paramètres de paie › Init. rôles GRH, puis déconnecter / reconnecter l'utilisateur concerné.

Le barème IR appliqué n'est pas le bon

Vérifier le pattern CodeBaremeIR_Annuel sur Paramètres de paie, et que le barème BaremeIR correspondant pour l'année existe, est Actif, et couvre bien la date du bulletin via DateDebut / DateFin.

Le canonique d'une rubrique a été modifié par erreur

Le canonique ne doit jamais changer après mise en production : le moteur de calcul s'en sert pour appliquer la formule. Restaurer la valeur d'origine depuis une sauvegarde ou via le script de seed.
