Import Salariés (Excel) - Guide RH

Ce guide décrit la procédure d'import en masse des salariés dans SunuPaie à partir d'un fichier Excel pré-formaté. Il s'adresse au RH opérationnel qui doit charger un lot de salariés en une seule opération : migration initiale depuis un ancien SIRH, intégration d'une promotion saisonnière, reprise d'un site racheté. L'opération est idempotente : les matricules déjà présents en base sont ignorés sans mise à jour, donc sans danger de la relancer.

Point d'entrée dans l'application

Les deux actions se trouvent côte à côte dans le Centre d'imports (et non dans la liste Salariés) :

Menu : Imports › Centre d'imports

  • Modèle Salariés : télécharge le fichier Excel modèle.
  • Importer Salariés : ouvre le popup qui accepte le fichier .xlsx rempli.

Pré-requis en base avant import

Les référentiels pointés par le fichier doivent exister avant l'import. Un libellé inconnu est ignoré silencieusement (champ laissé vide), pas bloquant.
  • Echelons (par Code) - si renseigné, aligne automatiquement SalaireBase, IndemniteLogement, Catégorie et Convention.
  • Départements (par Nom) et Fonctions (par Intitulé) - lookup insensible à la casse.
  • Sites (par Code ou par Nom).

2. Préparer le fichier Excel

2.1Télécharger le modèle

Deux sources équivalentes :

  • Dans l'application : Imports › Centre d'imports, bouton "Modèle Salariés". Le fichier Modele_Import_Salaries.xlsx est téléchargé.
  • Depuis la page d'accueil de l'aide (index.html), le lien direct vers Modele_Import_Salaries.xlsx.

Le modèle contient la ligne 1 d'en-têtes (fond vert, texte blanc, gras, figée) et une ligne 2 d'exemple en italique gris à supprimer avant l'import.

2.2Supprimer la ligne d'exemple

Ouvrir le fichier dans Excel ou LibreOffice Calc. Supprimer entièrement la ligne 2 (ligne d'exemple en italique gris). Sinon le salarié "SAL001 / DIOP / Moussa" sera créé lors du premier import.

2.3Saisir les données (une ligne = un salarié)

Renseigner au minimum les trois colonnes obligatoires : Matricule, Nom, Prenom. Les autres colonnes sont facultatives : une colonne vide ou absente n'est pas une erreur.

L'ordre des colonnes n'a pas d'importance : le service lit les en-têtes de la ligne 1 et retrouve les colonnes par nom (insensible à la casse).

2.4Enregistrer en .xlsx

Seul le format .xlsx est accepté. Les formats .xls, .csv, .ods ne sont pas lus. Enregistrer sous "Classeur Excel (*.xlsx)".

4. Lancer l'import

4.1Ouvrir le Centre d'imports

Menu : Imports › Centre d'imports. Les actions d'import sont regroupées ici (salariés, conjoints, comptes bancaires) pour éviter d'encombrer la liste Salariés.

4.2Lancer l'action "Importer Salariés"

Cliquer sur "Importer Salariés". Un popup s'ouvre avec un seul champ : Fichier Excel (.xlsx). Cliquer sur le champ, sélectionner le fichier préparé, puis cliquer sur "Importer".

Le service lit les en-têtes, vérifie que Matricule / Nom / Prenom sont présents, puis boucle sur chaque ligne de données. Pour un fichier de 100 lignes, le traitement prend quelques secondes.

4.3Pour chaque ligne, le service effectue

  1. Lit le matricule : si vide, ligne ignorée ; si déjà en base, ligne ignorée.
  2. Lit Nom et Prenom : si l'un des deux est vide, ligne en erreur.
  3. Crée l'objet Salarie et renseigne les champs présents.
  4. Si Echelon trouvé, applique l'alignement (SalaireBase / IndemniteLogement / Catégorie / Convention).
  5. Si PossedeVehicule coché, la prime de transport reste à la valeur saisie (la règle métier de non-cumul s'applique ensuite via la validation Salarié standard).
  6. Résout Département, Fonction et Site par lookup.

En fin de boucle, si au moins une création a réussi, un seul CommitChanges() est effectué sur l'ObjectSpace.

5. Idempotence et doublons

L'import est strictement idempotent : relancer le même fichier ne crée aucun doublon et ne modifie aucun salarié existant.

SituationComportement
Matricule inconnu, Nom et Prenom présentsCréation. Compteur Crees +1.
Matricule déjà en baseLigne ignorée. Compteur Ignores +1. Détail : "Ligne X : SAL001 existe déjà - ignoré."
Matricule videLigne ignorée. Compteur Ignores +1.
Nom ou Prenom vide (matricule présent)Ligne en erreur. Compteur Erreurs +1.
Exception imprévue sur une ligneLigne en erreur, message capturé. Les autres lignes continuent.
Conséquence pratique : pour mettre à jour un salarié existant, l'import est inopérant. Modifier la fiche directement, ou supprimer le salarié avant de ré-importer (uniquement si aucune donnée de paie n'est encore rattachée).

6. Vérification après import

6.1Lire le message de résultat

En fin d'import, un bandeau affiche : "X créé(s), Y ignoré(s), Z erreur(s)." Couleur verte si Z = 0, orange sinon. La liste Salariés est rafraîchie automatiquement si X > 0.

6.2Consulter le détail dans le journal d'audit

Chaque import est tracé dans Audit › Journal d'audit avec le résumé et la liste ligne par ligne des ignorés et des erreurs. Entité : Salarie, Action : Import en masse.

6.3Compléter les fiches créées

L'import ne couvre que les champs listés en section 3. Les éléments suivants doivent être ajoutés après l'import :

  • Conjoints (via Import Conjoints ou saisie manuelle).
  • Comptes bancaires (via Import Comptes bancaires ou saisie manuelle).
  • Pièces d'identité, photo.
  • Affectations multiples si applicable.
  • Reports de congés N-1 si la bascule arrive en cours d'année.

7. Dépannage et FAQ

"Colonne 'Matricule' introuvable" (ou 'Nom', 'Prenom')

L'en-tête obligatoire est manquant ou mal orthographié en ligne 1. Rouvrir le fichier modèle et vérifier que la ligne 1 porte exactement Matricule, Nom, Prenom (sans accent sur Prenom).

"Fichier Excel vide ou introuvable"

Le fichier uploadé fait 0 octet ou n'a pas été joint. Vérifier dans le popup que le nom du fichier apparaît bien à côté du champ avant de cliquer sur Importer.

"Ligne X : matricule vide - ignoré"

Comportement normal pour une ligne sans matricule. Souvent une ligne de total ou une ligne blanche en bas du fichier. Supprimer ces lignes.

"Ligne X : SAL001 existe déjà - ignoré"

Comportement normal : idempotence (voir section 5). Si une mise à jour est attendue, elle doit se faire manuellement sur la fiche.

Un salarié est créé mais son département ou sa fonction est vide

Le libellé saisi dans l'Excel n'a pas été trouvé en base (lookup insensible à la casse mais pas aux fautes de frappe). Créer le référentiel manquant puis affecter manuellement sur la fiche, ou supprimer le salarié et ré-importer après avoir créé le référentiel.

Un salarié a reçu Echelon mais le SalaireBase du fichier a été ignoré

Comportement attendu : si Echelon est renseigné et valide, les colonnes SalaireBase et IndemniteLogement du fichier sont volontairement ignorées. L'échelon fait foi. Pour saisir un salaire hors grille, laisser Echelon vide dans la ligne.

Rien ne se passe au clic sur "Modèle Salariés"

Le téléchargement passe par un JSInterop (AdiPAIE.downloadFile). Vérifier que le navigateur n'a pas bloqué le téléchargement (icône dans la barre d'adresse). A défaut, utiliser le lien direct depuis la page index.html de l'aide.
