Import en masse des salaries

Telecharger le fichier modele :
Ce fichier Excel contient les en-tetes attendus et une ligne d'exemple. Remplissez-le avec vos donnees puis importez-le dans SunuPaie.
Telecharger le modele (.xlsx)

Cette fonctionnalite permet d'importer plusieurs salaries en une seule operation a partir d'un fichier Excel (.xlsx). Ideal pour la migration initiale de donnees ou l'integration de nouveaux effectifs en lot.

Objectif

Creer rapidement des fiches salaries a partir d'un fichier Excel structure, sans saisie manuelle une par une. Le processus est idempotent : les salaries dont le matricule existe deja sont automatiquement ignores.

Boutons disponibles

Les deux boutons apparaissent sur la liste des salaries (menu Salaries).

Telecharger modele import : Genere et telecharge un fichier Excel modele vide (Modele_Import_Salaries.xlsx) avec les en-tetes attendus et une ligne d'exemple. Utilisez ce modele comme base pour preparer votre fichier d'import.
Importer depuis Excel : Ouvre un popup pour selectionner votre fichier Excel (.xlsx). Cliquez sur « Importer » pour lancer le traitement. Un message de resultat s'affiche a la fin.

Mode operatoire

Etape 1 — Telecharger le modele :
Allez dans la liste des salaries → cliquez sur « Telecharger modele import ». Un fichier Modele_Import_Salaries.xlsx est telecharge avec les en-tetes et une ligne d'exemple en italique gris.
Etape 2 — Preparer le fichier :
Ouvrez le modele dans Excel ou LibreOffice. Supprimez la ligne d'exemple (ligne 2) et remplissez vos donnees. Chaque ligne = un salarie. Enregistrez au format .xlsx.
Etape 3 — Importer :
Retournez dans la liste des salaries → cliquez sur « Importer depuis Excel ». Dans le popup, cliquez sur le champ fichier pour selectionner votre fichier .xlsx. Cliquez sur « Importer ».
Etape 4 — Verifier le resultat :
Un message s'affiche : « X cree(s), Y ignore(s), Z erreur(s) ». La liste des salaries est automatiquement rafraichie. Verifiez les fiches creees et completez-les si necessaire (conjoint, comptes bancaires, pieces d'identite, etc.).

Regles de traitement

  • Matricule unique : si un matricule existe deja en base, la ligne est ignoree (pas de doublons, pas de mise a jour).
  • Nom et Prenom obligatoires : les lignes sans nom ou prenom sont comptees comme erreurs.
  • Colonnes manquantes : si une colonne optionnelle est absente du fichier, elle est simplement ignoree.
  • Echelon prioritaire : si un echelon est renseigne et valide, SalaireBase et IndemniteLogement sont automatiquement calcules depuis l'echelon (les valeurs du fichier sont ignorees). La categorie et la convention sont aussi alignees.
  • Sexe ↔ Civilite : le sexe synchronise automatiquement la civilite (M → Monsieur, F → Madame).
  • Situation maritale : impacte directement le calcul des parts fiscales et du TRIMF sur les bulletins.
  • Vehicule : si PossedeVehicule = Oui, la PrimeTransport est automatiquement mise a zero.
  • Departement / Fonction / Echelon : doivent correspondre exactement a un element existant dans SunuPaie (la casse est ignoree). Si la valeur ne correspond a rien, le champ est laisse vide.
  • DateEmbauche par defaut : si la colonne est absente ou vide, la date du jour est utilisee.
  • Tracabilite : chaque import est enregistre dans le journal d'audit avec le detail ligne par ligne.

Prerequis

  • Creer d'abord les echelons, categories et conventions dans SunuPaie si vous utilisez la classification conventionnelle.
  • Creer d'abord les departements et fonctions si vous souhaitez les affecter automatiquement.
  • Le fichier doit etre au format .xlsx (Excel 2007+). Les formats .xls, .csv et .ods ne sont pas supportes.
  • La premiere ligne du fichier doit contenir les en-tetes. Les donnees commencent a la ligne 2.

Erreurs frequentes

Message Cause Solution
Colonne 'Matricule' introuvable La colonne Matricule est absente de la ligne 1 Verifiez l'orthographe exacte de l'en-tete : Matricule
Colonne 'Nom' introuvable La colonne Nom est absente de la ligne 1 Ajoutez une colonne Nom en premiere ligne
Colonne 'Prenom' introuvable La colonne Prenom est absente de la ligne 1 Ajoutez une colonne Prenom en premiere ligne
Fichier Excel vide ou introuvable Le fichier uploade est vide ou corrompu Re-enregistrez votre fichier et reessayez
Ligne X : matricule vide — ignore La cellule Matricule est vide sur cette ligne Renseignez un matricule unique pour chaque salarie
Ligne X : SAL001 existe deja — ignore Un salarie avec ce matricule est deja en base Normal : le systeme evite les doublons
