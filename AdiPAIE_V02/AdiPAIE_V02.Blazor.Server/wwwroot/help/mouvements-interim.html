🔁 Workflow Mouvements Intérimaires — Guide utilisateur

Ce module permet aux Assistants Commerciaux (AC) de soumettre des demandes de mouvement pour les intérimaires (changement de station, changement de poste, fin de mission anticipée, remplacement temporaire). Le workflow garantit la double validation Assistant RH → RH, avec une étape DAF optionnelle pour les mouvements à fort impact financier.

Exigence ELTON : aucun mouvement n'est effectif sans validation finale RH. La traçabilité (origine → destination, qui a validé, quand) est conservée dans le Dashboard N°3 Mouvements et la fiche de chaque intérimaire.

1. Rôles concernés

Rôle Responsabilité dans le workflow Vue principale
Assistant Commercial Initie une demande de mouvement pour un intérimaire d'une station qu'il gère. Mon espace → Mes demandes mouvement intérim
Assistant RH 1ʳᵉ validation : vérifie la cohérence et l'urgence avant transmission RH. Intérimaires → Demandes de mouvement (filtre statut Soumise)
RH 2ᵉ validation finale. Peut court-circuiter Assistant RH si absent. Appliquer le mouvement après validation. Intérimaires → Demandes de mouvement
DAF (option) Approuve uniquement si la demande coche Approbation DAF requise. Intérimaires → Demandes de mouvement (filtre statut Validée RH)

2. Vue d'ensemble du workflow

Brouillon
   ↓ [AC] Soumettre
Soumise (Asst RH)
   ├─ [Asst RH] Valider → Validée Asst RH
   │     ├─ [RH] Valider → Validée RH
   │     │     ├─ [option DAF] Approuver → Validée DAF
   │     │     │     └─ [RH] Appliquer → Appliquée ✓
   │     │     └─ [RH] Appliquer (sans DAF) → Appliquée ✓
   │     └─ [RH] Rejeter → Rejetée RH
   ├─ [Asst RH] Rejeter → Rejetée Asst RH
   └─ [RH] Court-circuit → Validée RH
                                                 ↓
                              (suite normale : DAF si option, puis Appliquer)

L'Annulation est possible à tout moment avant Appliquée, par l'initiateur (AC) ou par RH.

3. Prérequis (admin) — initialisation

3.1 Initialiser les rôles GRH

L'administrateur clique une fois sur le bouton Init. rôles GRH depuis Paramètres Paie. Cela crée 7 rôles dont AssistantCommercial et leurs permissions (idempotent — peut être relancé sans risque).

3.2 Affecter le rôle AC à un Salarié

Naviguer vers Administration → Utilisateurs, ouvrir l'utilisateur cible, onglet Roles, ajouter le rôle AssistantCommercial.

3.3 Assigner les stations sous responsabilité de l'AC

Ouvrir la fiche du Salarié AC, onglet Stations sous responsabilité (AC), cocher les stations qu'il gère.

Important : sans cette étape, l'AC verra la liste vide et ne pourra créer aucune demande (les intérimaires sont filtrés sur ses stations).

AC 4. Créer et soumettre une demande

4.1 Accéder à la liste

Menu : Mon espace → Mes demandes mouvement intérim. La liste affiche uniquement vos propres demandes.

4.2 Créer une nouvelle demande

Clic Nouveau. Remplir les champs :

  • Intérimaire concerné — lookup filtré sur les stations que vous gérez
  • Type de mouvement — choisir parmi :
    • Changement de Station Service (mutation interne)
    • Changement de poste / fonction
    • Fin de mission anticipée
    • Remplacement temporaire
    • Autre (motif libre — précision obligatoire)
  • Date souhaitée — date d'effet voulue
  • Champs adaptatifs selon le type :
    • Changement Station → Station destination
    • Changement Poste → Poste souhaité
    • Remplacement temporaire → Salarié titulaire absent + Durée (jours)
  • Motif — justification métier (obligatoire)
  • Pièce jointe — optionnel (email client, certificat médical, etc.)
  • Options workflow :
    • Notifier le RFE après application — envoi email automatique à la société d'intérim
    • Approbation DAF requise — ajoute une étape DAF avant application
Le champ Initiateur est rempli automatiquement avec votre fiche Salarié. Station origine et Poste actuel sont pré-remplis depuis le contrat actif de l'intérimaire (lecture seule).

4.3 Soumettre la demande

Sauvegarder, puis cliquer Soumettre. Le statut passe de Brouillon à Soumise (Asst RH).

Vous ne pouvez plus modifier la demande après soumission. Pour la corriger, demandez à RH ou Assistant RH de la rejeter — elle reviendra en Brouillon avec leur motif.

Asst RH 5. Valider ou rejeter

5.1 Voir les demandes en attente

Menu : Intérimaires → Demandes de mouvement. Filtrer sur statut Soumise (Asst RH).

5.2 Examiner la demande

Ouvrir la fiche, vérifier :

  • Cohérence : intérimaire actif, type de mouvement adapté
  • Date souhaitée : préavis raisonnable, planning compatible
  • Motif : justification claire
  • Pièce jointe : présence si requise

5.3 Valider

Saisir un commentaire (facultatif) dans Commentaire Assistant RH, puis cliquer Valider (Asst RH). Statut → Validée Asst RH. Transmise à RH.

5.4 Rejeter

Si la demande n'est pas recevable, saisir obligatoirement un motif dans Commentaire Assistant RH, puis cliquer Rejeter (Asst RH). Statut → Rejetée Asst RH. L'AC voit le motif et peut soumettre une nouvelle demande corrigée.

RH 6. Valider, court-circuiter ou rejeter

6.1 Validation normale

Sur une demande au statut Validée Asst RH, saisir un commentaire dans Commentaire RH, cliquer Valider RH. Statut → Validée RH.

6.2 Court-circuit Assistant RH

Si l'Assistant RH est absent ou indisponible, RH peut directement valider une demande au statut Soumise (Asst RH). Cliquer Valider RH sur la fiche : le système détecte automatiquement le court-circuit, l'audit l'enregistre comme tel.

Le court-circuit ne saute aucune étape de validation finale RH — il combine simplement les 2 étapes en une. À utiliser avec parcimonie pour ne pas court-circuiter le contrôle Assistant RH systématiquement.

6.3 Rejeter

Saisir un motif dans Commentaire RH (obligatoire), cliquer Rejeter RH. Statut → Rejetée RH.

DAF 7. Approbation DAF (option)

7.1 Quand l'étape DAF s'active

Uniquement si l'AC (ou RH après modification) a coché Approbation DAF requise. Typiquement pour les mouvements à fort impact financier (changement de station avec écart tarifaire, durée de remplacement étendue, etc.).

7.2 Approuver ou rejeter

Sur une demande Validée RH avec option DAF active, saisir un commentaire DAF, cliquer Approuver DAF ou Rejeter DAF.

RH 8. Appliquer la demande

8.1 Quand le bouton Appliquer est disponible

  • Sans option DAF → dès que statut = Validée RH
  • Avec option DAF → seulement après statut = Validée DAF

8.2 Effets de l'application

Le bouton Appliquer déclenche automatiquement :

  1. Création d'un MouvementInterimaire validé RH avec :
    • Date du mouvement
    • Type (mappé depuis le type de demande)
    • Station origine + Station destination (préservées pour l'historique)
    • Motif incluant la référence DMI
  2. Mise à jour du ContratInterim actif selon le type :
    • Changement Station → nouvelle Station sur le contrat
    • Changement Poste → nouveau Poste occupé
    • Fin mission anticipée → contrat fermé (statut Terminé + DateFinReelle)
    • Remplacement temporaire → pas de modification du contrat principal (juste l'enregistrement du mouvement)
  3. Si Notifier le RFE coché → email automatique à la société d'intérim (best-effort, non bloquant si SMTP en panne)
  4. Statut de la demande → Appliquée
  5. Lien Mouvement généré rempli sur la demande pour navigation rapide

9. Suivi et historique d'un intérimaire

9.1 Sur la fiche intérimaire

Onglet Mouvements : liste chronologique de tous les mouvements (incluant ceux générés par les demandes V1.5). Chaque ligne affiche origine → destination, type, date, qui a saisi.

9.2 Sur le Dashboard N°3 « Mouvements »

Le Dashboard N°3 agrège tous les mouvements de la période — y compris ceux des demandes appliquées. Filtres : Site, Période, Type de mouvement.

9.3 Audit complet

Chaque transition (soumission, validation, rejet, application, annulation) est auditée dans la table AuditEntry avec : utilisateur, date/heure, ancien statut → nouveau statut, commentaire. Consultable via Administration → Audit.

10. Cas particuliers

10.1 Annuler une demande

L'initiateur (AC) ou RH peut annuler une demande à tout moment avant qu'elle ne soit appliquée. Cliquer Annuler. Statut → Annulée. Une demande appliquée ne peut plus être annulée — créer une nouvelle demande pour défaire le mouvement.

10.2 Salarié AC sans station assignée

Si l'AC ouvre Mes demandes mouvement intérim sans avoir de station dans Stations sous responsabilité, il ne pourra pas créer de demande (lookup intérimaires vide). L'admin doit assigner les stations.

10.3 Email RFE sans adresse renseignée

Si l'option Notifier RFE est cochée mais que la société d'intérim de l'intérimaire n'a pas d'adresse email renseignée, l'application réussit (le mouvement est appliqué) et l'email est simplement skippé avec un log d'information. Aucun blocage.

10.4 Republication après correction

Une demande rejetée ne peut pas être ressuscitée. Pour la corriger, créer une nouvelle demande qui référence la précédente dans le motif (« Suite rejet DMI-2026-XXXXXX du JJ/MM/AAAA : … »).
